How to play

Left keys: tap, or hold for a map

Holding a left key turns the screen into a map that matches the GRID (columns 9–12). Pick with the GRID key at the same place.

  • ESC tap: next scene (INSTR → SEQ → TAPE), cancels pop-ups; in SETUP it goes back. Hold: scene map, GRID columns = 0 SETUP · 1 INSTR · 2 SEQ · 3 TAPE (column 1 is the only way into SETUP: project, files, keys, system).
  • TAB tap: next track. Hold: track map, a GRID column per track (row 1 select, 2 mute, 3 solo, 4 sequencer on/off). TAB + ADD/SUB: previous/next track.
  • FN is the menu of the current screen. Hold: the menu on the GRID, FN + GRID runs an item; tap: the menu stays open, a GRID key runs an item. 6/Y BPM, 7/U volume, 8/I octave; S save, C/V copy/paste, X clear, Q quantize, D duplicate, T tap tempo; FN + CTRL previous page, FN + ADD/SUB big steps.
  • CTRL tap: next page. Hold: page map of the scene. CTRL + ADD/SUB turns pages.

Pads, grid and the right column

  • PADS (columns 1–8) always play notes on the current track; on T1 drums each column is a drum.
  • GRID (columns 9–12) is the 4×4 cell grid in the middle of the screen: steps on SEQ, parameters and slots elsewhere.
  • ADD / SUB (+ / −) change values, hold to repeat. ENTER (OK) confirms; on the SEQ note page it is the record key: tap switches PIANO ROLL / STEP REC, hold opens RECORD (live REC and the captured takes). PLAY starts/stops; FN + PLAY arms recording.
  • HOME is not assigned yet; FN + ESC stops everything.

First loop

Boots on 1 INSTR (VOICE) with T1 drums: ADD/SUB try presets. Tap ESC for 2 SEQ, the drum machine: hold a drum pad and tap GRID keys to write steps, press PLAY (Space). Tap TAB for T2 Juno, where the pads are a piano. FN + ESC stops everything. Your work is kept in this browser as you go (also after a reload); save a project with FN + S, or in SETUP → PROJECT (hold ESC, press GRID column 1). Chord and arpeggiator are per track, on the INSTR pages after VOICE.

Computer keyboard

Keys map by position, whatever your layout: the digit row is row 0, Q row is row 1, A row is row 2, Z row is row 3. Esc or ` = ESC, Tab = TAB, Caps or Shift (left) = FN, Ctrl = CTRL, Backspace = ADD, \ = SUB, Enter = ENTER, Space = PLAY, Home = HOME. Each key shows its computer key at the bottom. On macOS Caps Lock latches FN (press again to release); hold left Shift for a momentary FN.

Mouse: press and hold a key. Right-click latches a key down (for holding ESC, FN… while clicking the GRID); right-click again to release. Touch: multi-touch works.

Projects and presets are kept in this browser (IndexedDB). Load project… copies .ccproj files from a Cardenza's card in here and opens the first; the rest are in SETUP, FILES. Load WAV… copies files into the sampler's Sample folder (stereo and 24-bit are mixed down to mono 16-bit at 44.1 kHz, whole file up to 5 min).
