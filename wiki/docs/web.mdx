# Web simulator

<Icon name="web" /> You can run Cardenza Synth directly in a desktop or mobile browser at [cardenza-synth.203.io](https://cardenza-synth.203.io/) (or [cardenza-synth.vercel.app](https://cardenza-synth.vercel.app/)). It compiles the actual firmware codebase (UI, AMY synth engines, sequencer, and storage layer) to WebAssembly, so the display, key LEDs, and audio match the hardware.

<Keywords k="simulator, emulator, web, browser, online, try it, try it live, no device, 模拟器" />

## Connect your Cardenza (USB) {#web-usb}

<Icon name="usb" /> Plug your Cardenza into your computer over USB using Chrome or Edge and open the [guide](/). The guide requests Web MIDI access automatically; once you allow it, your device connects whenever it is plugged in.

- **Interactive lessons**: the hardware switches to each lesson's screen and blinks the target keys (dimming others) until you complete the step, then lights them solid and prompts you to continue.
- **Safe for your projects**: starting a lesson saves your current session to the SD card and switches to a temporary practice project. Cardenza automatically restores your previous session when you leave the guide, close the tab, unplug USB, or the webpage stops communicating with the device for 30 seconds. An SD card must be inserted to run interactive lessons.
- **Manual pages**: reading the manual never takes over your connected hardware.
- **Plug and play**: unplug to disconnect, plug back in to reconnect automatically.
- **Protocol**: the guide communicates over Web MIDI with SysEx (no drivers required), leaving standard USB MIDI and USB audio working normally. If you previously denied MIDI access, enable MIDI devices in your browser's site settings (icon to the left of the address bar) and reload.

## Computer keyboard mapping {#web-keys}

<Icon name="keyboard" /> Your computer keyboard maps to Cardenza's 4×14 hardware layout by **physical key position**. Each keycap in the simulator shows its mapped key and lights up when pressed:

<Keymap>
  <Group keys="r0c1-r0c12">Number row (1 through =)</Group>
  <Group keys="r1c1-r1c12">Q row</Group>
  <Group keys="r2c1-r2c12">A row</Group>
  <Group keys="r3c1-r3c12">Z row</Group>
  <Group keys="ESC TAB FN CTRL">Esc · Tab · Caps Lock / Left Shift · Ctrl</Group>
  <Group keys="ADD SUB OK PLAY">Backspace · \\ · Enter · Space</Group>
  <Caption>Your computer keyboard's four rows map directly onto Cardenza's four rows.</Caption>
</Keymap>

| Hardware key | Computer key |
|---|---|
| <Key k="ESC" /> <Key k="TAB" /> <Key k="FN" /> <Key k="CTRL" /> | Esc / Tab / Caps Lock or Left Shift / Ctrl |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> <Key k="PLAY" /> | Backspace / `\` / Enter / Space |
| HOME side button | Home |
| Unlabeled pads | Right Shift (row 3) · Left / Right Alt (row 4) |

- The backquote key (left of `1`) also acts as <Key k="ESC" />. On macOS, Caps Lock latches <Key k="FN" /> until pressed again; hold Left Shift for momentary <Key k="FN" />.
- You can also click or multi-touch keys directly on screen. Right-clicking any key latches it down (handy for holding ESC or FN while clicking the GRID); right-click again to release.

<Keywords k="keyboard mapping, computer keyboard, which key, key bindings, shortcuts, caps lock, mac, right click, latch, 键位映射" />

## Sound {#web-audio}

<Icon name="sound" /> Browsers require a user gesture before unlocking audio, so click anywhere on the page (or click **Start audio**) to enable sound. Audio is synthesized live in the browser by the same AMY engine; output latency depends on your browser and OS.

<Keywords k="no sound, audio, start audio, sound not working, latency, 没声音" />

## Storage and samples {#web-storage}

- Settings, projects, and user presets persist in browser storage (IndexedDB) using the same `CardenzaSynth/...` folder layout as the SD card. Clearing site data wipes them.
- Session autosave ([Session autosave](./projects.mdx#project-session)) works in the browser too, saving as you edit and when switching tabs so your state survives reloads and closed tabs. Use <Key k="FN+S" /> to save named projects.
- Click **Load project...** to import `.ccproj` files from your computer or SD card into the simulator. Existing projects are never overwritten (duplicate names get numbered automatically); the first imported project opens immediately and the rest appear in SETUP FILES.
- Click **Load WAV...** to import audio files into the shared `Samples/` folder for use in SAMPLER. Files that are not mono 16-bit WAV (such as stereo, 24-bit, or MP3) are automatically converted to mono 16-bit 44.1 kHz and trimmed to 5 seconds.

<Keywords k="browser storage, autosave, kept after reload, indexeddb, load wav, upload sample, load project, import project, ccproj, where is it saved, reload, 浏览器存储" />
