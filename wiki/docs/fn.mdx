# FN menu and shortcuts

<Key k="FN" /> opens the **context menu** for whichever screen you are on. Hold <Key k="FN" /> to show the menu on the GRID and activate secondary shortcuts across the keyboard, or tap <Key k="FN" /> to latch the menu open.

<Keywords k="fn, function, second function, menu, shift" />

| Action | <Key k="hold FN" /> Hold FN | <Icon name="tap" /> Tap FN (latched menu) |
|---|---|---|
| Run an item | Press <Key k="FN" /> + its GRID key, or <Key k="FN" /> + its letter | Tap its GRID key (closes the menu) |
| Close menu | Release FN | Tap <Key k="FN" /> or <Key k="ESC" /> |
| PADS | Muted; only letter shortcuts and quick controls respond | Play notes normally |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> | Coarse adjustments (or next/previous pattern on SEQ note page with no step selected) and secondary OK action (see [Secondary functions and shortcuts](#fn-shortcuts)) | ADD/SUB are inactive; <Key k="FN+OK" /> still triggers the secondary OK action |

- Holding for 250 ms or longer counts as a hold; releasing sooner toggles the latched menu.
- **Visual feedback**: When you trigger an item while holding FN, its tile highlights yellow briefly after release and the status line at the bottom confirms the action (such as `COPIED P01` or `VIEW STEP`). Dimmed items are unavailable on the current screen and show `... NOT HERE` if pressed.
- Rows 1–3 change depending on the current page. Row 4 is always the same: **SAVE** project, **TAP** tempo, **REC** arm, and **SETUP** (which becomes **BACK** when you are already in SETUP).
- Global settings live in [0 SETUP](./setup.mdx) rather than FN sub-pages; <Key k="FN" /> + <Key k="1" />–<Key k="5" /> are unassigned.

Each menu tile displays:

- **Name and shortcut**: the action name at the top, with its yellow shortcut label in the top-right corner (`C` for <Key k="FN+C" />, `OK` for <Key k="FN+OK" />, `PLAY` for <Key k="FN+PLAY" />).
- **Target or state**: a second line showing what it acts on (`PATTERN`, `STEPS`, `ROW 2`, or engine name) or its current setting (`ROLL`, `120 BPM`, `OFF`).
- **LED status**: <Led state="half">half lit</Led> when available, <Led state="full">fully lit</Led> for active toggles (highlighted inverse on screen, such as `VIEW STEP`, `REC ARMED`, `PLAY SONG`), and <Led state="off">off</Led> with a dotted border when unavailable (such as `PASTE` with an empty clipboard or `SCOPE` with no steps selected).

## Menus by screen {#fn-menus}

| Screen | Rows 1–3 |
|---|---|
| INSTR (all pages) | **PRESETS** (browse), **SAVE** / **SAVE AS** preset, **ENGINE** picker, **RESET** `OK` (reset focused parameter on parameter, CHORD, and ARP pages). SAMPLER tracks also include **SAMPLES** (file browser), **RECORD** (mic recorder), and **PREVIEW**. |
| SEQ (all pages) | **COPY** `C`, **PASTE** `V`, **CLEAR** `X`, **QUANT** `Q` (apply to selected steps, or the whole pattern if none are selected), **DUP** `D` (duplicate pattern to the next empty slot, up to 16), **VIEW** (toggle ROLL/STEP; unavailable on drum tracks), **RECORD** (open RECORD panel and takes), **SCOPE** `OK` (edit all chord notes or a single note when steps are selected), **PAGE −** / **PAGE +** (switch 16-step pages on patterns longer than 16 steps), **LEN −** / **LEN +** (adjust pattern length from 1 to 256 steps: 1, 2, 4, 8, 16, then in 16-step increments). |
| TAPE SESSION | **LAUNCH** (trigger the cursor row), **ADD** TO SONG `OK` (append the currently playing/queued patterns as a new SONG section). |
| TAPE SONG | **COPY** `C`, **PASTE** `V` (insert after cursor), **DELETE** `X`, **DUP** `D` (act on the cursor section, `ROW n`), **PLAY** `OK` (toggle SONG/LOOP playback). |
| TAPE MIX | **UNMUTE** ALL, **UNSOLO** ALL. |
| TAPE SENDS / FX | **RESET** `OK` (restore focused parameter to default). |
| SETUP PROJECT / FILES | **NEW**, **LOAD**, **SAVE AS** (project actions). |
| SETUP KEYS / SYSTEM | **RESET** `OK` (restore focused setting to default). |
| **Row 4 (every screen)** | **SAVE** `S` (save project; shows `UNSAVED` when modified), **TAP** `T` (tap tempo and display BPM), **REC** `PLAY` (arm live recording; fully lit when armed), **SETUP** (jump to 0 SETUP; becomes **BACK** inside SETUP). |

## Quick controls: BPM, volume, octave {#fn-quick}

You can adjust BPM, master volume, and octave from any screen without leaving what you are doing. Hold <Key k="FN" /> and use the 2×3 block of keys on the right side of the pads (top row increases, bottom row decreases):

<Ref kind="fn-quick" />

All six keys repeat when held and show the updated value in a banner at the bottom of the screen. While <Key k="FN" /> is held, they glow <Led state="half">half lit</Led> and brighten to <Led state="full">fully lit</Led> when pressed.

  <Caption>Keys with secondary shortcuts while FN is held.</Caption>

| Shortcut | Function |
|---|---|
| <Key k="FN" /> + GRID | Run the corresponding menu item |
| <Key k="FN" /> + <Key k="ESC" /> | All stop: halt the sequencer, silence all sounding notes, and stop all arpeggiators (`ALL STOP`) |
| <Key k="FN" /> + <Key k="TAB" /> | Previous track |
| <Key k="FN" /> + <Key k="CTRL" /> | Previous page (<Key k="CTRL" /> alone moves to the next page) |
| <Key k="FN" /> + <Key k="ADD" /> / <Key k="SUB" /> | Coarse steps: ±10 on wide parameters (including BPM), ±3 on narrow ranges, ±5 on SETUP settings, ±10 presets on VOICE, 8 rows in browsers. On SEQ note page and PATTERN, selects the next/previous pattern (queued during playback; adjusts selected steps in coarse increments if steps are selected). |
| <Key k="FN" /> + <Key k="OK" /> | Context-specific secondary OK: reset focused parameter to default (INSTR, SENDS, Master FX, SETUP KEYS/SYSTEM); toggle chord edit scope between all notes and a single note (SEQ note page); add playing clips to SONG (SESSION); toggle SONG/LOOP mode (SONG); merge a captured take into the current pattern (RECORD panel); rename or delete file (sample list). |
| <Key k="FN" /> + <Key k="PLAY" /> | Arm or disarm live recording (REC) |
| <Key k="FN" /> + <Key k="C" /> / <Key k="V" /> | Copy / paste selected steps, current pattern, or SONG section |
| <Key k="FN" /> + <Key k="X" /> | Clear selected steps, clear current pattern (with confirmation), or delete SONG section |
| <Key k="FN" /> + <Key k="Q" /> | Quantize selected steps or the current pattern to whole steps |
| <Key k="FN" /> + <Key k="D" /> | Duplicate current pattern to the next empty slot, or duplicate current SONG section |
| <Key k="FN" /> + <Key k="T" /> | Tap tempo: tap two or more times to set BPM |
| <Key k="FN" /> + <Key k="S" /> | Save project (untitled projects are saved automatically as SONG 01, SONG 02, and so on) |
| <Key k="FN" /> + <Key k="F" /> | Open search filter in preset and sample browsers (see [FN in input screens: yellow legends](#fn-yellow)) |
| <Key k="FN" /> + <Key k="1" />–<Key k="5" /> | Unassigned |

:::note

Letter shortcuts are active whenever the current screen's FN menu includes that action (the pad lights up half lit to indicate availability). <Key k="S" /> and <Key k="T" /> work on every screen. When the FN menu is latched open with a tap rather than held, the pads continue playing notes instead of triggering letter shortcuts.

:::

## FN in input screens: yellow legends {#fn-yellow}

Inside overlays and input screens (text entry, preset/sample browsers, engine picker, RECORD panel, confirmations), holding <Key k="FN" /> switches to the **yellow legends** printed on the keycaps instead of opening the FN menu:

<Keymap>
  <Group keys="FN">Hold</Group>
  <Group keys=";">Up</Group>
  <Group keys=".">Down</Group>
  <Group keys=",">Left</Group>
  <Group keys="/">Right</Group>
  <Group keys="ADD SUB">Page up / down</Group>
  <Group keys="F">Search (browsers)</Group>
  <Caption>While holding FN in input screens, the four lower-right GRID keys work as arrow keys.</Caption>
</Keymap>

- Inside preset and sample lists, the pads do not type directly. Press <Key k="FN+F" /> to open a search box (up to 16 characters), then press <Key k="OK" /> to filter the list. Press <Key k="ESC" /> once to clear the filter, and again to close the browser.
- <Key k="FN+ESC" /> triggers All Stop in browsers and dialogs as usual, except during text entry where ESC cancels.

<Keywords k="arrows, arrow keys, cursor keys, up down left right, yellow legend, list, search, find, filter, fn f, 方向键" />

## Typing text {#fn-text}

When naming a project, preset, or sample, the entire keyboard switches to standard typing based on the printed keycaps:

  <Mark at="203,13,28,10">Character count / 24</Mark>
  <Mark at="footer">OK accept · DEL erase · ESC cancel</Mark>
  <KeyMark keys="ADD">Backspace (del)</KeyMark>
  <KeyMark keys="OK">Confirm</KeyMark>
  <KeyMark keys="ESC">Cancel</KeyMark>
  <KeyMark keys="PLAY">Space</KeyMark>
  <Caption>Text entry screen for SAVE PROJECT AS.</Caption>
</Shot>

- Allowed characters: letters, digits, spaces (using <Key k="PLAY" />, not allowed as the first character), and `-`, up to 24 characters (16 for search queries). SAVE AS pre-fills the current project name (or `SONG`).
- Press the top-right key (`del`) to backspace, <Key k="OK" /> to confirm, or <Key k="ESC" /> to cancel.
- Hold <Key k="FN" /> with <Key k="," /> / <Key k="/" /> to move the cursor left/right, with <Key k=";" /> / <Key k="." /> to jump to the start/end, and with `del` to forward-delete.
- The cursor renders as a vertical bar between characters and as a block at the end of the line.
