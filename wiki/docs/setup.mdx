# 0 SETUP

**SETUP** (scene 0) sits outside the normal <Key k="ESC" /> scene cycle and houses project management, shared keyboard configuration, and device settings. Step through its four pages with <Key k="CTRL" /> (or hold <Key k="CTRL" /> for the page map):

<Page name="PROJECT" /> <Page name="FILES" /> <Page name="KEYS" /> <Page name="SYSTEM" />

| Pages | Scope | Where saved |
|---|---|---|
| PROJECT, FILES | Current project and saved project files | Project files on SD card (includes BPM and swing) |
| KEYS | Shared keyboard settings for all four tracks | Saved per project (except `SELECT`, which is a global app preference) |
| SYSTEM | Hardware and device settings | Shared across all Cardenza apps, independent of projects |

Chord and arpeggiator settings are per-track and live on the **CHORD** and **ARP** pages of <Scene name="INSTR" /> (see [Chord and arpeggiator](#setup-chord-arp)).

<Keywords k="setup, settings, global, settings page, preferences, options, project, files, keys, chord, arp, system, scene 0, 设置, 全局" />

## Getting in and out {#setup-open}

<Strip>
  <Step keys="hold ESC" shot="map-esc" at="cells:1,1-4,1">Hold <Key k="ESC" /> to open the scene map. Column 1 is **0 SETUP**, set apart by a dotted border and dimmed number.</Step>
  <Step keys="hold ESC + G1" shot="setup-project" at="8,0,41,11">Press any key in column 1 to enter SETUP on whichever page you used last.</Step>
  <Step keys="ESC" shot="instr-voice" at="scene">Tap <Key k="ESC" /> inside SETUP to return to the scene you came from (INSTR in this example).</Step>
</Strip>

- Tapping <Key k="ESC" /> only cycles through 1 INSTR, 2 SEQ, and 3 TAPE; it never enters SETUP (see [Scenes: ESC](./navigate.mdx#nav-scenes)).
- You can also open SETUP from the bottom-right tile of any FN menu (see [Menus by screen](./fn.mdx#fn-menus)). Inside SETUP, that same tile changes to **BACK** and returns you to your previous scene.
- The pads stay active inside SETUP so you can audition keyboard and volume changes immediately.

| GRID row | Controls |
|---|---|
| Row 1 | **SAVE** (save current project), **LOAD** (jump to FILES), **NEW** (start a fresh default project; prompts if there are unsaved changes) |
| Row 2 | **BPM** (30–300) and **SWING** (50–75%): tap to focus and adjust with <Key k="ADD" /> / <Key k="SUB" />. **TAP**: tap repeatedly in time to set BPM. **PLAY**: toggle between LOOP and SONG playback (lights fully in SONG mode; see [SONG: arranging the song](./tape.mdx#tape-song)). |

- Pressing <Key k="OK" /> saves the project unless **TAP** is focused, in which case <Key k="OK" /> taps tempo.
- Hold <Key k="FN" /> with <Key k="ADD" /> / <Key k="SUB" /> for coarse steps (BPM ±10, swing ±5). Hold **BPM** or **SWING** on the GRID to map its full range across the 32 pads (lowest at top left, highest at bottom right) and tap any pad to jump directly.
- Untitled projects auto-name to the next available slot (`SONG 01`, `SONG 02`, etc.) on SAVE. To enter a custom name (up to 24 characters using letters, digits, spaces, and `-`), choose **SAVE AS** in the FN menu (see [Typing text](./fn.mdx#fn-text)). Overwriting an existing project name prompts for confirmation (<Key k="OK" /> to overwrite, <Key k="ESC" /> to cancel).
- **NEW** creates a blank project with the default four tracks, C major scale, no chords, and all arpeggiators off. Your `SELECT` preference is preserved.
- The **PLAY** (LOOP/SONG) toggle is a live performance control and is not stored in project files.

The FN menu on PROJECT and FILES:

| GRID row | Items |
|---|---|
| Row 1 | **NEW** PROJECT, **LOAD** PROJECT (opens FILES), **SAVE AS** PROJECT |
| Row 4 | **SAVE** (<Key k="FN+S" />; displays `UNSAVED` when modified), **TAP** (<Key k="FN+T" />), **REC** (<Key k="FN+PLAY" />), **BACK** (return to previous scene) |

## FILES {#setup-files}

Lists all projects stored on the SD card alphabetically, marking the currently loaded project with `>`.

<Shot name="setup-files">
  <Mark at="content">Project file list</Mark>
  <Mark at="footer">FILES (page 2 of 4)</Mark>
  <Caption>SETUP FILES page (displays NO PROJECTS ON THE CARD if empty).</Caption>
</Shot>

- Scroll with <Key k="ADD" /> / <Key k="SUB" /> (hold <Key k="FN" /> to jump 8 rows at a time) and press <Key k="OK" /> to load.
- If the current project has unsaved edits, Cardenza asks for confirmation before loading (<Key k="OK" /> to discard and load, <Key k="ESC" /> to keep working).
- Loaded projects open on T1 and restore their saved keyboard, chord, and arpeggiator settings (older project files that did not store those settings keep your current ones).
- Projects saved by release 0.1.0 live in the same folder and appear here automatically (see [Folders on the SD card](./projects.mdx#storage-layout)). Re-saving a project updates it to format 7, which 0.1.0 cannot read.
- Without an SD card inserted, this list is empty (see [No card or card errors](./projects.mdx#storage-card)).

Configures pad behavior across all four tracks. All settings here save with the project except **SELECT**, which is a global app preference.

  <Caption>SETUP KEYS page with seven settings and a two-octave keyboard preview.</Caption>

| Setting | Options | Reference |
|---|---|---|
| LAYOUT | PIANO, SCALE, CHROMA | [Keyboard layouts](./play.mdx#play-keyboard) |
| SCALE / ROOT | 14 scales / C–B | [Scale and root](./play.mdx#play-scale) |
| OCTAVE | −3 to +3 | [Octave](./play.mdx#play-octave) |
| VELO | 1–127 (default 110); fixed velocity for melodic pads | [Velocity](./play.mdx#play-velocity) |
| LOCK | OFF, MUTE, SNAP | [Scale lock](./play.mdx#play-lock) |
| SELECT | How GRID taps select steps in SEQ (ROLL, STEP, DRUMS): **ONE** selects a single step at a time; **MULTI** toggles steps in and out of a multi-step selection | [Selecting and editing](./seq.mdx#seq-edit) |

Both settings pages (**KEYS** and **SYSTEM**) share the same controls:

| Action | Keys |
|---|---|
| Focus a setting | Tap its GRID key (focused cell inverts) |
| Adjust value | <Key k="ADD" /> / <Key k="SUB" /> (hold to repeat; <Key k="FN+ADD" /> / <Key k="FN+SUB" /> for steps of 5) |
| Jump directly to a value | Hold the setting's GRID key to map its range across the pads (lowest top left, highest bottom right) |
| Cycle options or toggles | Tap the focused GRID key again, or press <Key k="OK" /> |
| Reset to default | Press <Key k="FN+OK" />, or choose **RESET** in the FN menu |

Each settings page remembers your last focused cell.

## SYSTEM {#setup-system}

<Shot name="setup-system">
  <Mark at="cell:1,1">VOLUME (focused)</Mark>

  <KeyMark keys="G1">Focused: fully lit</KeyMark>
  <KeyMark keys="G2 G3 G4">Settings: half lit</KeyMark>
  <Caption>SETUP SYSTEM page: hardware settings and device status readout.</Caption>
</Shot>

| Setting | Range | Description |
|---|---|---|
| VOLUME | 0–100 (default 70, steps of 2) | Perceptually scaled master output volume: 0 is silent, 1 ≈ −59 dB, 50 ≈ −21 dB, 70 ≈ −10 dB, 100 = full scale (coarser at quiet levels, finer near full volume). Linked with **MASTER** on [MIX](./tape.mdx#tape-mix) and <Key k="FN" /> + <Key k="7" /> / <Key k="U" /> ([Quick controls](./fn.mdx#fn-quick)). |
| KEY LED | 0–15 (default 15) | Master brightness for all key LEDs. Focusing this cell displays a brightness ramp across the pads ([Brightness and the light test](./lights.mdx#lights-ramp)). |
| SCREEN | 3–100% (default 70%) | Display backlight brightness. |
| LOG | ON / OFF (default ON) | Writes diagnostic and crash logs to the SD card ([Diagnostic logs](./projects.mdx#storage-log)). |

Device settings are shared across all Cardenza apps, stored in `CardenzaSynth/Settings/system.cfg`, and never overwritten when loading projects.

The lower section displays live device diagnostics whenever you open SYSTEM: firmware **VERSION**, **SD CARD** status (`READY` or `NOT FOUND`; see [No card or card errors](./projects.mdx#storage-card)), free **MEMORY** (internal RAM, minimum watermark, and PSRAM), and **BUILD** commit/timestamp.
