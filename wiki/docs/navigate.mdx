# Navigation

Four scenes with a few pages each, and four tracks you can switch at any time. The four left keys do all the navigation:

<Keymap>
  <Group keys="ESC">Scenes</Group>
  <Group keys="TAB">Tracks</Group>
  <Group keys="FN">The menu of this screen</Group>
  <Group keys="CTRL">Pages</Group>
  <Caption>The four left keys handle all the navigation</Caption>
</Keymap>

<Keywords k="navigation, switch, move around, where am i, 导航" />

## Scenes: ESC {#nav-scenes}

Four scenes in two kinds, numbered as on the screen. 0 SETUP comes first and holds everything global; 1, 2 and 3 are the music itself:

| Scene | For | Pages |
|---|---|---|
| <Scene name="SETUP" /> setup | global: the project and its files, the keyboard for every track, the system | PROJECT, FILES, KEYS, SYSTEM |
| <Scene name="INSTR" /> instrument | what the current track sounds like: engine, sound, its chord and ARP, parameters, effects | VOICE, CHORD, ARP, engine pages, FX (drums: VOICE, KIT, FX) |
| <Scene name="SEQ" /> sequencer | what the current track plays: notes, recording, patterns | ROLL / STEP (DRUMS on a drum track), PATTERN, TRACK |
| <Scene name="TAPE" /> tape | all four tracks together: launching, the song, the mix, sends, master effects | SESSION, SONG, MIX, SENDS, FX |

**Tap <Key k="ESC" />**: the three music scenes in turn, 1 → 2 → 3 → 1. The groovebox starts in <Scene name="INSTR" /> on the VOICE page, on track <Track n="1" />.

<Strip>
  <Step keys="ESC" shot="seq-notes" at="scene"><Scene name="SEQ" />: write notes.</Step>
  <Step keys="ESC" shot="tape-session" at="8,0,41,11"><Scene name="TAPE" />: launch, arrange and mix.</Step>
  <Step keys="ESC" shot="instr-voice" at="8,0,41,11">Back to <Scene name="INSTR" />: sounds and parameters.</Step>
</Strip>

**Hold <Key k="ESC" />**: the scene map, four tall columns, one per scene; press any key of a column to jump straight there. The tap ring never enters SETUP: **column 1 is the way in**.

<Shot name="map-esc">
  <Mark at="cells:1,1-4,1">0 SETUP: dotted rule, dim number</Mark>
  <Mark at="cells:1,2-4,2">1 INSTR</Mark>
  <Mark at="cells:1,3-4,3">2 SEQ (current)</Mark>
  <Mark at="cells:1,4-4,4">3 TAPE</Mark>
  <Mark at="162,0,70,11">Tap ESC = 1 > 2 > 3</Mark>
  <KeyMark keys="ESC">Hold</KeyMark>
  <KeyMark keys="G3 G7 G11 G15">Current scene: fully lit</KeyMark>
  <KeyMark keys="G1 G5 G9 G13">SETUP: half lit</KeyMark>
  <Caption>Holding ESC: four columns = four scenes, each listing its pages; the page you would land on is marked.</Caption>
</Shot>

<Strip>
  <Step keys="hold ESC + G2" shot="instr-voice" at="8,0,41,11">Tap column 2: straight to <Scene name="INSTR" />. Release ESC and the map folds away.</Step>
  <Step keys="hold ESC + G1" shot="setup-project" at="8,0,41,11">Tap column 1: <Scene name="SETUP" />, on the page you were last on.</Step>
  <Step keys="ESC" shot="seq-notes" at="scene">In SETUP a tap on <Key k="ESC" /> goes back to the scene you came from.</Step>
</Strip>

:::note

In a pop-up <Key k="ESC" /> cancels; in SEQ with steps selected, ESC clears the selection first. The FN menu also reaches SETUP (its bottom-right item, see [The menu on each screen](./fn.mdx#fn-menus)).

:::

## Tracks: TAB {#nav-tracks}

Four tracks, with the same colour everywhere: <Track n="1" /> pink, <Track n="2" /> blue, <Track n="3" /> lime, <Track n="4" /> amber.

<Strip>

  <Step keys="hold TAB" shot="map-tab" at="cells:1,1-4,4">Hold TAB: the track map, laid out like the MIX page.</Step>
</Strip>

<Shot name="map-tab">

- <Key k="TAB" /> + <Key k="ADD" /> / <Key k="SUB" />: next / previous track (the map's title says so).
- Row 1 of the map shows each track's engine and sound; rows 2 to 4 switch at once, like on MIX.
- <Key k="FN+TAB" />: previous track.

## Pages: CTRL {#nav-pages}

The page tabs are at the bottom of the screen, the current one on violet (like <Page name="ROLL" />); when there are too many you see `<` `>` at the ends and "current / total" on the right.

<Strip>
  <Step keys="CTRL" shot="seq-pattern" at="footer">Tap CTRL: next page (on release).</Step>
  <Step keys="hold CTRL" shot="map-ctrl" at="cells:1,1-1,3">Hold CTRL: the page map; each cell shows the tab and a short description.</Step>
  <Step keys="hold CTRL + G3" shot="seq-track" at="footer">Tap a cell to jump to that page; you stay there after releasing.</Step>
</Strip>

- <Key k="CTRL" /> + <Key k="ADD" /> / <Key k="SUB" />: next / previous page; <Key k="FN+CTRL" />: previous page.
- Each track remembers which INSTR page it was on.
- The page map's title: TAP CTRL = NEXT.

<Keywords k="page, pages, next page, sub page, tabs, 页面, 翻页" />

## Hold a left key = a map {#nav-maps}

Hold <Key k="ESC" />, <Key k="TAB" /> or <Key k="CTRL" /> for more than 250 ms and the middle of the screen becomes a map: **each cell sits on the GRID key that picks it**. Holding <Key k="FN" /> shows the menu of the current screen instead, laid out the same way (see [The FN menu](./fn.mdx#fn-menu)).

<Shot name="map-ctrl">
  <Mark at="cell:1,1">Current page</Mark>
  <Mark at="cell:1,2">Another page</Mark>
  <Mark at="header">Map title and hint</Mark>
  <KeyMark keys="CTRL">Hold</KeyMark>

  <KeyMark keys="G2 G3">Half lit: can pick</KeyMark>

| Light | Means |
|---|---|
| <Led state="full">fully lit</Led> | the current item |
| <Led state="half">half lit</Led> | can be picked |
| <Led state="off">off</Led> | nothing there; while you hold, the pads are off too (silent) |

Release the left key and the map folds away.

## Back and cancel {#nav-back}

<Shot name="confirm">
  <Mark at="10,70,104,26">OK confirms</Mark>
  <Mark at="125,70,104,26">ESC cancels</Mark>
  <Mark at="8,43,172,11">Consequence (in red)</Mark>
  <KeyMark keys="OK">Blinking: waiting for you</KeyMark>
  <KeyMark keys="ESC">Cancel</KeyMark>
  <Caption>Anything destructive always asks first, with the consequence written in red.</Caption>
</Shot>

- In a pop-up (lists, confirmations, text entry, the RECORD panel, the open FN menu) <Key k="ESC" /> closes or cancels.
- In <Scene name="SETUP" /> <Key k="ESC" /> goes back to the scene you came from.
- In a confirmation <Key k="OK" /> confirms and <Key k="ESC" /> cancels; overwriting, deleting and discarding unsaved work always ask first.
- In SEQ with steps selected <Key k="ESC" /> clears the selection first.

<Keywords k="back, cancel, close, exit, undo selection, 返回, 取消" />
