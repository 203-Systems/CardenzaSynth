# Navigation

Cardenza is organized into four scenes (each with multiple pages) and four tracks that you can switch between at any time. All navigation is handled by the four keys in the left column.

<Keymap>
  <Group keys="ESC">Scenes</Group>
  <Group keys="TAB">Tracks</Group>
  <Group keys="FN">Current screen menu</Group>
  <Group keys="CTRL">Pages</Group>
  <Caption>All navigation lives on the left column.</Caption>
</Keymap>

<Keywords k="navigation, switch, move around, where am i, 导航" />

## Scenes: ESC {#nav-scenes}

The four scenes are numbered 0 through 3, matching the top-left label on screen. **0 SETUP** holds global project and system settings, while **1 INSTR**, **2 SEQ**, and **3 TAPE** are the three music-making scenes.

| Scene | Purpose | Pages |
|---|---|---|
| <Scene name="SETUP" /> Setup | Global project management, files, shared keyboard settings, and device settings | PROJECT, FILES, KEYS, SYSTEM |
| <Scene name="INSTR" /> Instrument | Active track's sound design: engine, preset, chord, arpeggiator, synth parameters, and effects | VOICE, CHORD, ARP, engine pages, FX (drums: VOICE, KIT, FX) |
| <Scene name="SEQ" /> Sequencer | Active track's patterns, note entry, editing, and recording | ROLL / STEP (DRUMS on a drum track), PATTERN, TRACK |
| <Scene name="TAPE" /> Tape | All four tracks together: clip launching, song arrangement, mixer, sends, and master effects | SESSION, SONG, MIX, SENDS, FX |

**Tap <Key k="ESC" />** to cycle through the three music scenes (`1 → 2 → 3 → 1`). At boot, Cardenza starts on <Scene name="INSTR" /> VOICE with track <Track n="1" /> selected.

<Strip>
  <Step keys="ESC" shot="seq-notes" at="scene"><Scene name="SEQ" /> for writing and editing notes.</Step>
  <Step keys="ESC" shot="tape-session" at="8,0,41,11"><Scene name="TAPE" /> for launching patterns, arranging songs, and mixing.</Step>
  <Step keys="ESC" shot="instr-voice" at="8,0,41,11">Back to <Scene name="INSTR" /> for choosing and tweaking sounds.</Step>
</Strip>

**Hold <Key k="ESC" />** to display the scene map: four vertical columns, one per scene. Press any key in a column to jump straight to that scene. Tapping <Key k="ESC" /> never cycles into SETUP; **holding ESC and pressing column 1** is how you open it.

:::note

Inside pop-ups and dialogs, <Key k="ESC" /> cancels or closes them. In SEQ, if steps are selected, <Key k="ESC" /> clears the selection first. You can also reach SETUP from the bottom-right tile of any FN menu (see [Menus by screen](./fn.mdx#fn-menus)).

:::

## Tracks: TAB {#nav-tracks}

The four tracks keep consistent color coding throughout the interface: <Track n="1" /> pink, <Track n="2" /> blue, <Track n="3" /> lime, and <Track n="4" /> amber.

  <Step keys="hold TAB" shot="map-tab" at="cells:1,1-4,4">Hold <Key k="TAB" /> to open the track map, which uses the same layout as the MIX page.</Step>
</Strip>

- Hold <Key k="TAB" /> and press <Key k="ADD" /> / <Key k="SUB" /> to step forward or backward through tracks.
- Row 1 shows each track's engine and preset name. Rows 2–4 toggle mute, solo, and sequencer state immediately, just like on MIX.
- Press <Key k="FN+TAB" /> to jump to the previous track.

## Pages: CTRL {#nav-pages}

Page tabs sit along the bottom of the screen, with the current page highlighted in violet (like <Page name="ROLL" />). When a scene has more pages than fit on screen, `<` and `>` arrows appear along with a `page / total` indicator on the right.

<Strip>
  <Step keys="CTRL" shot="seq-pattern" at="footer">Tap <Key k="CTRL" /> to advance to the next page (triggers on release).</Step>
  <Step keys="hold CTRL" shot="map-ctrl" at="cells:1,1-1,3">Hold <Key k="CTRL" /> to open the page map, where each cell shows a tab name and short label.</Step>
  <Step keys="hold CTRL + G3" shot="seq-track" at="footer">Tap a cell to jump straight to that page; it stays open when you release CTRL.</Step>
</Strip>

- Hold <Key k="CTRL" /> and press <Key k="ADD" /> / <Key k="SUB" /> to move forward or backward through pages, or press <Key k="FN+CTRL" /> for the previous page.
- Each track remembers its own active page in <Scene name="INSTR" />.
- The page map header displays `TAP CTRL = NEXT` as a reminder.

<Keywords k="page, pages, next page, sub page, tabs, 页面, 翻页" />

## Hold a left key for a map {#nav-maps}

Holding <Key k="ESC" />, <Key k="TAB" />, or <Key k="CTRL" /> for more than 250 ms turns the screen into an interactive map where each cell lines up with its matching GRID key. Holding <Key k="FN" /> works the same way for the current screen's context menu (see [The FN menu](./fn.mdx#fn-menu)).

|---|---|
| <Led state="full">fully lit</Led> | Currently active item |
| <Led state="half">half lit</Led> | Selectable item |

Releasing the left key closes the map.

## Back and cancel {#nav-back}

<Shot name="confirm">
  <Mark at="10,70,104,26">OK confirms</Mark>
  <Mark at="125,70,104,26">ESC cancels</Mark>
  <Mark at="8,43,172,11">Warning text in red</Mark>
  <KeyMark keys="OK">Blinking: awaiting confirmation</KeyMark>
  <KeyMark keys="ESC">Cancel</KeyMark>
  <Caption>Destructive actions always prompt for confirmation with the consequence highlighted in red.</Caption>
</Shot>

- In pop-ups (browsers, confirmations, text entry, the RECORD panel, or a toggled FN menu), <Key k="ESC" /> cancels or closes the overlay.
- Inside <Scene name="SETUP" />, <Key k="ESC" /> returns to the previous scene.
- In confirmation prompts, <Key k="OK" /> confirms and <Key k="ESC" /> cancels. Overwriting files, deleting data, and discarding unsaved edits always require confirmation.
- In SEQ, if steps are selected, <Key k="ESC" /> clears the selection before switching scenes.

<Keywords k="back, cancel, close, exit, undo selection, 返回, 取消" />
