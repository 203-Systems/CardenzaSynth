# Key lights

Every key has a single-color LED showing its current role and state. There are three steady brightness states plus blinking:

| LED | State | Meaning |
|---|---|---|
| <Led state="off" /> | **off** | Inactive or empty |
| <Led state="half" /> | **half lit** | Available or populated, not selected |
| <Led state="full" /> | **fully lit** | Selected, active, or currently sounding |
| <Led state="blink" /> | **blinking** | Pending or waiting for input |

| State | Meaning | Examples |
|---|---|---|
| <Led state="off">off</Led> | Inactive or empty | Empty step, unmapped pad (piano gap or muted out-of-scale key), unavailable action, bypassed send |
| <Led state="half">half lit</Led> | Present or available | Step containing notes, playable pad, editable parameter, available menu item, existing pattern |
| <Led state="full">fully lit</Led> | Selected or active | Selected step, focused parameter, active scene/track/page/pattern, held or playing pad, playhead position, enabled switch (mute, solo, sequencer on) |
| <Led state="blink">blinking</Led> | Waiting | Queued pattern, cued SONG section, OK during a confirmation dialog, PLAY while recording is armed |

:::note

Hardware keys support 16 gamma-corrected PWM brightness levels (scaled globally by the **KEY LED** setting). The UI intentionally sticks to three levels: off, "half lit" (lowest visible glow, 1/15 duty cycle), and "fully lit" (100%). Animations never illuminate keys that should be off. The eight outer edge keys cap at half lit physically, showing their full-brightness state on the screen's matching edge strips instead (see [Screen edges mirror the key lights](#lights-edges)).

:::

| Screen | GRID LEDs |
|---|---|
| SEQ note page (ROLL, STEP, DRUMS) | Empty steps off, populated steps half lit, selected steps fully lit, playhead fully lit, steps past pattern length off. While holding pads (with no steps selected), steps containing those notes light fully. |
| SEQ PATTERN | Existing patterns half lit, active pattern fully lit, queued pattern blinking; NEW and empty slots off. |
| SEQ TRACK | All four settings half lit, focused setting fully lit. |
| RECORD panel | Settings and takes half lit; focused cell and enabled REC/SNAP toggles fully lit. |
| INSTR parameter pages (including CHORD, ARP) | Parameters and actions half lit, focused parameter (and active HOLD) fully lit, unused cells off. |
| TAPE SESSION | Active pattern per track fully lit, other patterns half lit, queued patterns blinking. |
| TAPE SONG | Cells with a pattern half lit, `--` off, selected cell and playing row fully lit, cued row blinking. |
| TAPE MIX | Active track fully lit; mute, solo, and SEQ fully lit when on, half lit when off. |
| TAPE SENDS / FX | Active sends half lit, off sends off, focused cell fully lit; on Master FX, parameters half lit and focus fully lit. |
| SETUP PROJECT | Actions half lit, focused BPM/SWING fully lit, PLAY fully lit in SONG mode. |
| SETUP FILES | Off (navigate with ADD/SUB). |
| SETUP KEYS / SYSTEM | Settings half lit, focused setting fully lit (focusing KEY LED turns the pads into a brightness test ramp). |
| Holding ESC | Four columns for the four scenes: active scene fully lit, others half lit (column 1 = SETUP); pads off. |
| Holding TAB / CTRL | Available map keys half lit, current item fully lit; pads off. |
| Holding FN / FN menu | Available items half lit, active toggles fully lit, unavailable items and empty slots off. |
| Holding a parameter cell | Pads show selectable values (half lit) with the current value fully lit. |
| Text entry | Typing keys, Backspace, OK, and Space half lit. |

- **PADS**: reflect the active track's keyboard layout. Playable pads glow half lit; held keys, chord tones, arpeggiator notes, and sequencer notes glow fully lit; unplayable keys stay off (see [Keyboard layouts](./play.mdx#play-keyboard)). In SEQ, pads light up for the selected step's notes, or for the playing step's notes during playback.
- **Drum tracks**: the one exception to the three-level rule. Idle drum pads are half lit, holding a pad lights its column from the bottom up to that row, and hits animate up the column higher for harder velocities. On screen, drum pads use four dither densities to show velocity.
- **Left column**: ESC, TAB, and FN stay half lit (CTRL is half lit whenever a scene has multiple pages); held keys light fully; latching the FN menu keeps FN fully lit while turning TAB and CTRL off (as in all overlays). After switching tracks, only the key in the new track's row flashes briefly (T1 = ESC row through T4 = CTRL row).
- **Right column**: ADD/SUB glow half lit when adjustable; OK glows half lit when active (fully lit in SEQ STEP view); PLAY is half lit when stopped, fully lit when playing, and blinking when record-armed.

While holding <Key k="FN" />, the entire keyboard previews every active FN action on the current screen:

| Keys | State while FN is held |
|---|---|
| GRID | Available items <Led state="half">half lit</Led>, active toggles <Led state="full">fully lit</Led>, unavailable/empty slots <Led state="off">off</Led> |
| PADS | Active menu letter shortcuts (<Key k="C" /> <Key k="V" /> <Key k="X" /> <Key k="Q" /> <Key k="D" />, <Key k="S" /> <Key k="T" />) and quick controls (<Key k="6" /> <Key k="7" /> <Key k="8" /> <Key k="Y" /> <Key k="U" /> <Key k="I" />) half lit; all other pads off |
| <Key k="ESC" /> <Key k="TAB" /> <Key k="CTRL" /> | ESC and TAB half lit; CTRL half lit when the scene has multiple pages |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> <Key k="PLAY" /> | ADD/SUB half lit; OK half lit if the screen supports <Key k="FN+OK" />; PLAY half lit (fully lit when record-armed) |

## Screen edges mirror the key lights {#lights-edges}

The four left and four right strips along the screen edges directly mirror the LED state of the eight physical edge keys. Because those eight physical keys cap at half brightness, their full-brightness state is shown on the screen strips.

| Key LED | On-screen edge strip |
|---|---|
| <Led state="off">off</Led> | Very faint |
| <Led state="half">half lit</Led> | 30% dither pattern |
| <Led state="full">fully lit</Led> | Solid fill (right-side icon turns black) |

Holds, track hints, maps, and blinking always stay synchronized between the physical keys and the screen strips. Right-side strips also display context-sensitive icons for ADD/SUB (▲ ▼ for values/lists, → ← for horizontal navigation, or delete in text entry), while PLAY turns green during playback and red when recording is armed.

:::tip

When idle (no key pressed for 4 seconds), a subtle light sweep runs down both edges every 10 seconds, pulsing each row's physical edge keys in sync with the screen strips.

:::
