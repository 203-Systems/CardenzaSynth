## Every key at a glance {#ref-shortcuts}

**Navigation and transport keys**

| Keys | Function |
|---|---|
| <Key k="ESC" /> tap | Cycle scenes (`1 INSTR → 2 SEQ → 3 TAPE`); exit SETUP; cancel a dialog; clear step selection in SEQ |
| <Key k="hold ESC" /> + <Key k="GRID" /> | Open scene map (`0 SETUP`, `1 INSTR`, `2 SEQ`, `3 TAPE`); column 1 enters SETUP |
| <Key k="TAB" /> tap | Next track |
| <Key k="hold TAB" /> + <Key k="GRID" /> | Open track map (MIX layout: select, mute, solo, sequencer on/off) |
| <Key k="TAB" /> + <Key k="ADD" /> / <Key k="SUB" /> | Next / previous track |
| <Key k="CTRL" /> tap | Next page |
| <Key k="hold CTRL" /> + <Key k="GRID" /> | Open page map and jump directly to any page in the current scene |
| <Key k="CTRL" /> + <Key k="ADD" /> / <Key k="SUB" /> | Next / previous page |
| <Key k="FN" /> tap | Latch the current screen's FN menu open or closed (tapping a GRID item runs it and closes the menu) |
| <Key k="hold FN" /> | Display FN menu while held and activate secondary shortcuts across the keyboard |
| <Key k="ADD" /> / <Key k="SUB" /> | Adjust value or scroll lists (hold to auto-repeat with acceleration); flip 16-step pages on SEQ note page when no steps are selected |
| <Key k="GRID" /> on SEQ note page | Tap to latch step selection (tap again to deselect); hold to select temporarily; hold pads and tap GRID to toggle notes |
| <Key k="OK" /> | Confirm, open, or toggle; on SEQ note page: tap to switch ROLL/STEP, hold for RECORD panel, or tap with steps selected to cycle `NOTE → LEN → VEL → TIME` |
| <Key k="PLAY" /> | Play / stop |
| HOME side button | Open system menu (Back to Launcher, Restart, Power off, Download mode; Cardenza Synth 0.2.1+) |
| Hold a GRID parameter cell | Map that parameter's values across the 32 pads for direct selection |

**FN combinations**

| Keys | Function |
|---|---|
| <Key k="FN+GRID" /> | Run the corresponding FN menu item |
| <Key k="FN" /> + <Key k="6" /> / <Key k="Y" /> | BPM + / − (global; hold to repeat) |
| <Key k="FN" /> + <Key k="7" /> / <Key k="U" /> | Master volume + / − |
| <Key k="FN" /> + <Key k="8" /> / <Key k="I" /> | Octave + / − |
| <Key k="FN+ESC" /> | All stop: stop sequencer, all arpeggiators, and all sounding notes |
| <Key k="FN+TAB" /> | Previous track |
| <Key k="FN+CTRL" /> | Previous page |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | Coarse adjustment (BPM ±10, SETUP settings ±5); next/previous pattern on SEQ note page with no steps selected; page up/down in browsers |
| <Key k="FN+OK" /> | Secondary OK: RESET parameter default, chord edit SCOPE (SEQ), ADD TO SONG (SESSION), SONG/LOOP toggle (SONG), merge take (RECORD panel), rename/delete (sample browser) |
| <Key k="FN+PLAY" /> | Arm / disarm live recording (REC) |
| <Key k="FN+C" /> / <Key k="FN+V" /> | Copy / paste (selected steps, pattern, or SONG section) |
| <Key k="FN+X" /> | Clear steps/pattern (prompts on full pattern) or delete SONG section |
| <Key k="FN+Q" /> | Quantize selected steps or full pattern to whole steps |
| <Key k="FN+D" /> | Duplicate current pattern or SONG section |
| <Key k="FN+T" /> | Tap tempo |
| <Key k="FN+S" /> | Save project (auto-names untitled projects as `SONG 01`, `SONG 02`, ...) |

**FN in input screens** (browsers, text entry, dialogs)

| Keys | Function |
|---|---|
| <Key k="FN" /> + <Key k=";" /> <Key k="." /> <Key k="," /> <Key k="/" /> | Up / down / left / right (in text entry: jump to start/end, move cursor left/right) |
| <Key k="FN+F" /> | Filter preset or sample browser by name |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | Page up / page down |
| <Key k="ADD~del" /> / <Key k="FN" /> + <Key k="ADD~del" /> | Backspace / forward-delete in text entry |
| <Key k="OK" /> / <Key k="ESC" /> | Confirm / cancel |

## Glossary {#glossary}

| Term | Definition |
|---|---|
| Track | One of four independent channels (T1–T4), each with its own engine, patterns, chord generator, and arpeggiator |
| Engine | Sound generator assigned to a track: DRUMS, JUNO, DX7, or SAMPLER |
| Preset / sound | Saved set of parameters for an engine |
| Step | Smallest sequencer grid unit (1/16 note) |
| Microstep | One of 6 subdivisions per step, used for off-grid timing |
| Pattern | 1 to 256-step sequence (viewed 16 steps per page); up to 16 patterns per track |
| Song row / part | One section in SONG mode defining each track's pattern and bar length (shown as columns in SONG, labeled `ROW n` in the FN menu) |
| Scene | One of four top-level views: 0 SETUP, 1 INSTR, 2 SEQ, 3 TAPE |
| SETUP | Scene 0, holding project files and global keyboard/system settings (hold ESC + GRID column 1) |
| FN menu | Context menu shown on the GRID while holding FN or after tapping FN |
| Take | A phrase buffered automatically by retrospective capture |
| Autosave | Background session snapshot written to the SD card so power can be removed safely |
| GRID | 4×4 key block on the right mirroring the screen's 4×4 cell layout |
| PADS | 4×8 key block in the center used to play the active track |
| Send | Level routed from a track into the shared master delay or reverb bus |
| Master bus | Global processing chain (EQ, compressor, tape saturation) applied to the summed mix |
