# Getting started

:::tip

New to Cardenza? Start with the interactive [guide](/) for short, step-by-step lessons. This manual is the reference for looking up specific features and shortcuts.

:::

Cardenza Synth is a pocket four-track groovebox. It includes four engines (drums, a Juno-style analog synth, a DX7 FM synth, and a sampler), per-track pattern sequencers, song arrangement, a mixer, track and master effects, and SD card project storage.

The keyboard is divided into four color-coded sections. Throughout this manual, each key is shown in the same color used on the device screen.

<Keymap>
  <Group keys="ESC TAB FN CTRL">Left column: navigation and menus</Group>
  <Group keys="PADS">PADS: play the active track</Group>
  <Group keys="GRID">GRID: select cells shown on screen</Group>
  <Group keys="RIGHT">Right column: values, confirm, and playback</Group>
  <Caption>The four key blocks: navigation on the left, playable pads in the middle, the 4×4 GRID matching the screen cells, and value/transport keys on the far right.</Caption>
</Keymap>

| Color | Key | Role |
|---|---|---|
| <Key k="ESC" /> red-orange | Scenes | Switch between 1 INSTR, 2 SEQ, 3 TAPE, and 0 SETUP |
| <Key k="TAB" /> cyan | Tracks | Switch between <Track n="1" /> <Track n="2" /> <Track n="3" /> <Track n="4" /> |
| <Key k="FN" /> yellow | Secondary functions | Context menu for the current screen and shortcuts |
| <Key k="CTRL" /> violet | Pages | Bottom page tabs within a scene, such as <Page name="ROLL" /> |
| <Key k="PLAY" /> green | Transport | Start and stop playback |

## One-minute start {#quick-start}

Run through these steps once to get the basics down:

<Strip>
  <Step shot="instr-boot" at="8,0,41,11 51,0,15,11 10,89,220,38">At startup, Cardenza opens in <Scene name="INSTR" /> on the VOICE page with track <Track n="1" /> selected (808 KIT drums). Each column of pads plays a different drum, with higher rows hitting harder.</Step>
  <Step keys="ESC" shot="seq-empty" at="scene">Tap <Key k="ESC" /> to open <Scene name="SEQ" /> and program notes. On a drum track, this opens the drum sequencer, showing the drums on the left and the selected drum's 16 steps on the GRID.</Step>
  <Step keys="hold r3c1~Kick + G1, G5, G9, G13" shot="seq-drums" at="9,17,92,10">Hold the kick pad and tap GRID keys 1, 5, 9, and 13 to place a kick on every beat. Add snare and hi-hat hits the same way.</Step>
  <Step keys="PLAY" shot="seq-drums-playing">Press <Key k="PLAY" /> to start the sequencer. Each step triggers when the green playhead crosses it. Press again to stop.</Step>
  <Step keys="TAB" shot="seq-keyboard" at="track">Tap <Key k="TAB" /> to switch to <Track n="2" /> (Juno). The pads become a two-octave piano keyboard: white keys on rows 2 and 4, black keys on rows 1 and 3, unlit gaps where no black key exists, and C3 at the bottom left.</Step>
  <Step keys="hold r3c1~C3 + G1" shot="seq-hold-tap" at="28,57,15,10">Hold a note on the pads and tap a GRID step to enter it. Held keys glow at full brightness.</Step>
  <Step keys="hold OK" shot="record">Everything you play is captured automatically in the background. Hold <Key k="OK" /> to open the RECORD panel and drop a recent take into a pattern.</Step>
</Strip>

Four more essentials to keep in mind:

<Strip>
  <Step keys="hold ESC" shot="map-esc" at="cells:1,1-4,4">Tapping <Key k="ESC" /> cycles through the three performance scenes: <Scene name="INSTR" /> (sound) → <Scene name="SEQ" /> (notes) → <Scene name="TAPE" /> (arrangement and mix). Holding <Key k="ESC" /> opens the scene map, where column 1 opens <Scene name="SETUP" /> for projects and settings.</Step>
  <Step keys="hold FN" shot="fn-held" at="cells:1,1-4,4">Hold <Key k="FN" /> to display the current screen's context menu on the GRID (copy, paste, save, record, and more), then press a GRID key to run an action.</Step>
  <Step keys="hold FN + 7" shot="fn-volume" at="14,94,212,28">While holding <Key k="FN" />, use <Key k="6" /> / <Key k="Y" /> for BPM, <Key k="7" /> / <Key k="U" /> for master volume, and <Key k="8" /> / <Key k="I" /> for octave.</Step>
  <Step keys="FN+S" shot="save-done" at="footer">Press <Key k="FN+S" /> anywhere to save the current project. Untitled projects are automatically named SONG 01, SONG 02, and so on.</Step>
</Strip>

## What is on the screen {#screen-layout}

The 240×135 display is arranged into five areas that line up with the physical keys around it:

<Shot name="seq-notes">
  <Mark at="scene">Scene</Mark>
  <Mark at="track">Track (in its track color)</Mark>
  <Mark at="bpm">BPM and play state</Mark>
  <Mark at="strip:ESC">ESC</Mark>
  <Mark at="strip:TAB">TAB</Mark>
  <Mark at="strip:FN">FN</Mark>
  <Mark at="strip:CTRL">CTRL</Mark>
  <Mark at="content">Content area (16 steps = the GRID)</Mark>
  <Mark at="strip:PLAY">PLAY</Mark>
  <Mark at="footer">Page tabs (CTRL switches pages)</Mark>
  <KeyMark keys="PADS">Playable keys: half lit</KeyMark>
  <KeyMark keys="G1">Step with notes: half lit</KeyMark>
  <KeyMark keys="G2">Empty step: off</KeyMark>
  <Caption>The SEQ ROLL view with a few notes on T2, shown above the matching key LEDs.</Caption>
</Shot>

| Area | Position | Contents |
|---|---|---|
| Status bar | Top | Scene number and name, active track (color-coded), engine and preset, REC indicator, play/stop status, BPM, and `*` when there are unsaved changes |
| Left edge strips | Left edge | Indicators for <Key k="ESC" /> <Key k="TAB" /> <Key k="FN" /> <Key k="CTRL" /> with role icons (back, tracks, menu, pages); holding a key fills its strip |
| Content area | Center | A 4×4 grid of cells mapped directly to the 4×4 GRID keys on the right |
| Page tabs | Bottom | Pages in the current scene, with the active page highlighted in violet (like <Page name="ROLL" />); press <Key k="CTRL" /> to switch pages |
| Right edge strips | Right edge | Indicators for <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> <Key k="PLAY" />; ADD/SUB icons show their current direction (▲ ▼ for values/lists, → ← for horizontal navigation), and PLAY turns green during playback or red when recording is armed |

:::tip

The cell at row 2, column 3 on screen corresponds to row 2, column 3 on the GRID (the `[` key). Every screen follows this 1:1 spatial layout.

:::

The eight edge strips mirror their keys' LED states: <Led state="off">off</Led> looks faint, <Led state="half">half lit</Led> uses a 30% dither pattern, and <Led state="full">fully lit</Led> fills solid. Because the physical edge keys cap at <Led state="half">half lit</Led>, the on-screen strips show when they are active or full. See [Screen edges mirror the key lights](./lights.mdx#lights-edges).
