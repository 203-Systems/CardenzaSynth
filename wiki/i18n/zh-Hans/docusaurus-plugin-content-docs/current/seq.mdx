# 2 SEQ 音序器

每条轨道最多 16 个 Pattern。每个 Pattern 有自己的长度，1–256 步（开始是 16 步），GRID 一次显示其中一页 16 步。每步最多 8 个音（和弦），每个音有自己的长度、力度和微小的时间偏移（每步 6 个微步）。SEQ 有三页：

| 页 | 做什么 |
|---|---|
| <Page name="ROLL" /> / <Page name="STEP" /> 音符页 | 写音符、改音符、录音。两种视图：ROLL 钢琴卷帘（默认）和 STEP 步进录制；鼓轨上是 <Page name="DRUMS" /> 鼓机 |
| <Page name="PATTERN" /> | 选择、新建、排队切换这一轨的 Pattern |
| <Page name="TRACK" /> | 这一轨的音序开关、当前 Pattern 的长度，全局 Swing 和 BPM |

<Keywords k="音序器, 编曲, 节奏, 循环, pattern, sequencer, sequence, steps, loop, beat" />

## 音符页的两种视图 {#seq-notes}

<Key k="OK" /> 是这一页的 <Icon name="rec" /> **录音键**：单击在两种视图之间切换，按住打开 RECORD 面板。有选中的步时，单击 <Key k="OK" /> 是换编辑项（见 [选中与编辑](#seq-edit)）。

<Strip>
  <Step shot="seq-notes" at="footer"><Icon name="roll" /> **ROLL 钢琴卷帘**（默认）：时间 × 音高，音符画成条。</Step>
  <Step keys="OK" shot="seq-step-view" at="footer"><Icon name="step" /> 单击 <Key k="OK" />：**STEP 步进录制**，4×4 步格写着音名。</Step>
  <Step keys="OK" shot="seq-notes" at="footer">再单击：回到 ROLL。屏幕上的 OK 色块 ROLL 时 <Led state="half" />、STEP 时 <Led state="full" />。</Step>
</Strip>

两种视图编辑同一个 Pattern，GRID 的 16 个键都对应屏幕上这一页的 16 步（第 1 行是第 1–4 步，第 2 行是 5–8 步……）。

|  | <Icon name="roll" /> ROLL | <Icon name="step" /> STEP |
|---|---|---|
| 屏幕 | 时间 × 音高，音符画成条 | 4×4 步格，写着音名或和弦 |
| GRID 单击 | 走到这一步（再点一次放开）；SELECT MULTI 时可多选 | 把写入光标移到这一步 |
| 弹 PADS | 有选中的步时加 / 删音符；没有时就是弹奏（REC 打开时实时录音） | 写进光标所在的步，松开后光标前进 |
| <Key k="ADD" /> / <Key k="SUB" /> | 调整选中的步；没有选中时切换下一个 / 上一个 Pattern | 光标移动一步 |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | 选中的步大步调整；没有选中时长 Pattern 翻到下一页 / 上一页 | 光标移动一页（只有一页的 Pattern 是 4 步） |

<Keywords k="视图, 模式切换, 钢琴卷帘, 步进, 卷帘窗, view, piano roll, step view, mode" />

横向是这一页的 16 步，纵向是音高（自动显示用到的音域，至少一个八度，黑键行带底纹）。音符越实力度越大；绿色竖线是播放头；底部小格：有音符的步带点阵，选中的步白色，播放头所在的步绿色。空的 Pattern 上写着 HOLD A PAD + TAP STEPS。

**写音符：按住一个或几个 PADS，再点 GRID 上的步。**

<Strip>
  <Step keys="hold r2c1~C" shot="seq-hold-pad">按住一个音（C）。</Step>
  <Step keys="hold r2c1~C + G1" shot="seq-hold-tap" at="28,57,15,10">不松手，点 GRID 1：第 1 步写进 C。</Step>
  <Step keys="hold r2c1~C + G5, G9" shot="seq-notes" at="28,110,195,11">继续点 5、9……换个音再点几步。</Step>
</Strip>

- **走到一步**：单击 GRID 走到那一步，那一步的音在演奏区全亮，一眼就知道这一步有没有音；再点同一步放开。见 [选中与编辑](#seq-edit)。
- **实时录音**：打开 REC（<Key k="FN+PLAY" /> 或 RECORD 面板），播放，然后弹，见 [播放与实时录音](#seq-transport)。
- 这一轨的音序关掉时（TRACK 页），这一页上写着 SEQUENCE OFF。

## STEP 步进录制 {#seq-step-rec}

一步一步把音写进去，不用跟着节拍：

<Strip>
  <Step keys="OK" shot="seq-step-view" at="cell:1,1 footer">单击 <Key k="OK" /> 进入 STEP 视图。红色蚂蚁线框是**写入光标**。</Step>
  <Step keys="G2, r2c2~D" shot="seq-step" at="cell:1,2">点 GRID 2 把光标放到那里，再按一个 PAD：D 写进第 2 步。同时按几个就是和弦。</Step>
  <Step keys="r2c3~E" shot="seq-step" at="cell:1,3 cell:1,4">松开后光标自动前进：E 写进第 3 步，光标停在第 4 步（角上的「+1」）。</Step>
  <Step keys="ADD"><Key k="ADD" /> 跳过一步（休止），<Key k="SUB" /> 往回。</Step>
  <Step keys="hold r2c1~C + G16">按着 PADS 点 GRID：直接写到那一步。</Step>
</Strip>

  <Mark at="212,30,17,9">每次前进几步</Mark>

  <Mark at="footer">STEP 视图</Mark>

- 按下去会替换光标那一步原来的音。
- 每次前进几步在 RECORD 面板的 STEP 里设（1 / 2 / 4）。
- 写进去的音用 SETUP KEYS 的力度（VELO），长度一步。之后可以切回 ROLL 细调。
- 长 Pattern 里光标走到哪一页，GRID 就跟到哪一页；<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 一次移动一整页。
- 播放时，播放头走进的那一步绿色闪一下，然后保持绿框直到下一步；走过的步不留拖尾。
- FN 菜单里的 VIEW 也能切换视图，SEQ 的每一页都行。

## 选中与编辑 {#seq-edit}

在 ROLL 视图里单击 GRID **走到一步**：只选中这一步，换一步就跟着走过去，再点同一步放开（演奏区又回到弹奏）。走到的那一步，它的音在演奏区全亮；没有音的步，演奏区只有很暗的键盘。想一次选几步，在 <Scene name="SETUP" /> 的 KEYS 页把 **SELECT** 改成 MULTI（见 [KEYS 键盘](./setup.mdx#setup-keys)）。

播放时（没有选中步），播放头走到的那一步，它的音也在演奏区亮起来。走到一步之后：

<Strip>
  <Step keys="G5" shot="seq-selected" at="76,15,14,96">单击 GRID 5：第 5 步选中，这一列高亮。</Step>
  <Step keys="OK, OK" shot="seq-lane" at="footer"><Key k="OK" /> 循环编辑项 **NOTE → LEN → VEL → TIME**，底行是正在改的项和数值。</Step>
  <Step keys="ADD" shot="seq-lane" at="footer"><Key k="ADD" /> / <Key k="SUB" /> 调整，按住连发。<Key k="ESC" /> 取消选择。</Step>
</Strip>

| 键 | 作用 |
|---|---|
| PADS | 在选中的步上加上或去掉这个音（和弦里的每个音都能单独加减）；播放中只编辑，不发声 |
| <Key k="OK" /> | 编辑项 NOTE（音高）→ LEN（长度）→ VEL（力度）→ TIME（微小的时间偏移） |
| <Key k="ADD" /> / <Key k="SUB" /> | 调整，按住连发；加 <Key k="FN" /> 是大步 |
| <Key k="FN+OK" /> | 「和弦里所有的音」（ALL）和「其中一个音」（底行显示音名）之间切换编辑对象 |
| <Key k="ESC" /> | 取消选择（再按 ESC 才换场景） |

选中时，演奏区上这一步的音 <Led state="full">全亮</Led>。

## DRUMS 鼓机页 {#seq-drums}

鼓轨（默认 <Track n="1" />）的音符页是 <Page name="DRUMS" /> 鼓机，没有 ROLL / STEP。

<Shot name="seq-drums">
  <Mark at="9,15,95,108">八种鼓 × 16 步</Mark>
  <Mark at="106,15,125,108">选中的鼓在 GRID 上</Mark>
  <Mark at="footer">DRUMS 页</Mark>
  <KeyMark keys="G1 G3 G5">选中的鼓（CH）的击打：全亮</KeyMark>
  <KeyMark keys="G2">这一步什么都没有：灭</KeyMark>
  <Caption>T1 的 DRUMS：左边是每种鼓的节奏，右边是选中的鼓的 16 步。</Caption>
</Shot>

- **PADS** 选鼓和力度：每一列是一种鼓，每一行是力度（最上面一行最重）。按下会发声，之后 GRID 就用这个鼓、这个力度来写。
- **GRID**：点空的步立刻加一击（停止时听得到）；点已有的一击，松手时去掉。
- **按住一击**：屏幕显示它的值，<Key k="ADD" /> / <Key k="SUB" /> 改力度；<Key k="OK" /> 切换成改它在这一步里的时间（6 个微步），再按切回。改过或按得久的一击会留下。

<Strip>
  <Step keys="hold G1" shot="seq-drums" at="110,26,28,24">按住 CH 第 1 步的那一击（不要松手）。</Step>
  <Step keys="hold G1 + ADD" shot="seq-drum-edit" at="12,96,213,25">再按 <Key k="ADD" />：力度变大，屏幕显示 CH VELOCITY。松手后这一击留下。</Step>
</Strip>

- GRID 灯：选中的鼓的击打全亮，只有别的鼓的步半亮，空步灭。
- 鼓轨没有 ROLL / STEP 视图；实时录音和 RECORD 面板和别的轨一样用。

## 无感录制：把刚才弹的找回来 {#capture}

<Icon name="capture" /> 不用开 REC：你在演奏区弹的每一个音都会在后台记下来（Capture）。弹得好的那一段，事后放进音序器：

<Strip>
  <Step keys="r2c1~C, r2c3~E, r2c5~G" shot="seq-keyboard">随便弹。停顿超过 2.5 秒、换轨或超过 60 秒，就开始新的一段（take）。</Step>
  <Step keys="hold OK" shot="record" at="cells:2,1-3,4">按住 <Key k="OK" />：中间两行是最近 8 段 take，编号、轨道、音符数。</Step>
  <Step keys="G6" shot="record" at="cell:2,2 cells:4,1-4,4">点一个 take：第 4 行是它这一小节放进去的样子。<Key k="ADD" /> / <Key k="SUB" /> 换小节。</Step>
  <Step keys="OK" shot="record-placed" at="14,94,212,28"><Key k="OK" />：放进这一轨的**新 Pattern**，原有的一个音都不动。</Step>
</Strip>

- 8 段 take 一共能记 400 个音；记满时最旧的一段让出位置。
- 没有空 Pattern 时会提示，用 <Key k="FN+OK" /> 合并进当前 Pattern。
- 播放中弹的 take 按小节线对齐；停止时弹的 take 从第一个音开始，按当时的 BPM 计时。
- SNAP 打开时（默认）每个音对齐到最近的整步，长度也取整步；关掉则保留弹的细微时间。

## 长 Pattern 与翻页 {#seq-long}

一个 Pattern 最长 256 步；GRID 和屏幕永远显示其中一页 16 步。页码在底行右端（例如 `2/4`，自己翻过页时是黄色）。

<Shot name="fn-held">
  <Mark at="cells:3,1-3,2">PAGE − / PAGE +：第几页 / 共几页</Mark>
  <Mark at="cells:3,3-3,4">LEN − / LEN +：长度</Mark>
  <Caption>SEQ 菜单（按住 FN）：第 3 行翻页、设长度。</Caption>
</Shot>

- **设长度**：TRACK 页的 STEPS（<Key k="ADD" /> / <Key k="SUB" /> 一步，<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 跳到下一个整页），或 FN 菜单的 LEN − / LEN +：1、2、4、8、16、32、48 … 256。
- **翻页**：音符页上没有选中步时 <Key k="FN+ADD" /> / <Key k="FN+SUB" />，或 FN 菜单的 PAGE − / PAGE +。
- 播放时 GRID 跟着播放头一页一页翻；自己翻过页后就停在那一页，直到下一次 PLAY。有选中的步时不翻页。
- 新建的 Pattern 沿用当前 Pattern 的长度；复制的 Pattern 保留自己的长度。超出长度的步在 GRID 上是灭的。
- 只有写了音符的页才占内存。内存不够时这个音不写入，屏幕提示 MEMORY FULL。

## 复制、粘贴、清除、量化 {#seq-tools}

按住 <Key k="FN" /> 用字母键，或在 FN 菜单里选（COPY、PASTE、CLEAR、QUANT、DUP，第二行写着 STEPS 还是 PATTERN）。音符页里作用于选中的步；没有选中时，以及在 PATTERN、TRACK 页，作用于整个 Pattern：

<Keymap>
  <Group keys="FN">按住</Group>
  <Group keys="C">复制</Group>
  <Group keys="V">粘贴</Group>
  <Group keys="X">清除</Group>
  <Group keys="Q">量化</Group>
  <Group keys="D">复制 Pattern</Group>
  <Group keys="T">敲速度</Group>
  <Caption>按住 FN 的编辑键</Caption>
</Keymap>

| 键 | 作用 |
|---|---|
| <Key k="FN+C" /> / <Key k="FN+V" /> | 复制 / 粘贴（复制过才能粘贴） |
| <Key k="FN+X" /> | 清除（整个 Pattern 时会先确认） |
| <Key k="FN+Q" /> | 量化到整步 |
| <Key k="FN+D" /> | 复制 Pattern 到下一个空槽 |
| <Key k="FN+T" /> | 敲击设定速度 |

GRID 上的 SEQ 菜单，三页都一样：

| 行 | 项 |
|---|---|
| 1 | COPY · PASTE · CLEAR · QUANT |
| 2 | DUP · VIEW（ROLL / STEP）· RECORD（RECORD 面板）· SCOPE（<Key k="FN+OK" />，有选中的步时） |
| 3 | PAGE − · PAGE +（音符页，长 Pattern）· LEN − · LEN + |
| 4 | SAVE · TAP · REC · SETUP，每个画面都一样 |

菜单的更多说明见 [每个画面的菜单](./fn.mdx#fn-menus)。

:::warning

没有撤销，所以清除整个 Pattern 前一定会确认。

:::
