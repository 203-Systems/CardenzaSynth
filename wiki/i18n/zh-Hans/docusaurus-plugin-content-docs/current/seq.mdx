# 2 SEQ 音序器

每条轨道最多可存储 16 个 Pattern。每个 Pattern 拥有独立长度（1–256 步，默认 16 步），在 GRID 上按每页 16 步分页显示。单步最多容纳 8 个同时发声的音符，每个音符均具备独立的时值、力度与微时间偏移（每步细分 6 个微步）。

**SEQ** 包含三个子页面：

| 页面 | 用途 |
|---|---|
| <Page name="ROLL" /> / <Page name="STEP" />（音符页） | 编写、编辑与录制音符，提供钢琴卷帘（ROLL）与步进网格（STEP）两种视图；鼓轨的 STEP 视图为 <Page name="DRUMS" /> 鼓机 |
| <Page name="PATTERN" /> | 切换、新建与排队切换当前轨道的 Pattern |
| <Page name="TRACK" /> | 控制当前轨音序开关、Pattern 长度，以及全局 Swing 与 BPM |

<Keywords k="音序器, 编曲, 节奏, 循环, pattern, sequencer, sequence, steps, loop, beat" />

## 音符页的两种视图 {#seq-notes}

在音符页中，<Key k="OK" /> 兼作 <Icon name="rec" /> **视图与录音键**：单击可在 ROLL 与 STEP 视图间切换，长按则打开 RECORD 面板。当已选中步进时，单击 <Key k="OK" /> 会改为循环切换步进编辑项（见[选中与编辑](#seq-edit)）。

<Strip>
  <Step shot="seq-notes" at="footer"><Icon name="roll" /> **ROLL（钢琴卷帘）**：横向为时间、纵向为音高，音符以横条显示。旋律轨默认打开此视图。</Step>
  <Step keys="OK" shot="seq-step-view" at="footer 116,14,113,108"><Icon name="step" /> 单击 <Key k="OK" /> 切换至 **STEP 视图**：左侧按音高分行总览整页，右侧以 4×4 排布显示演奏区最后按下音符的步进。鼓轨默认打开此视图（页签为 DRUMS）。</Step>
  <Step keys="OK" shot="seq-notes" at="footer">再次单击 <Key k="OK" /> 切回 ROLL。屏幕上的 OK 边条在 ROLL 下呈 <Led state="half">半亮</Led>，在 STEP 下呈 <Led state="full">全亮</Led>。</Step>
</Strip>

两种视图编辑的是同一个 Pattern，按键操作完全一致，仅画面呈现方式不同。鼓轨与旋律轨会各自记住偏好的视图。GRID 的 16 颗按键对应当前页的 16 步（第 1 行对应第 1–4 步，第 2 行对应第 5–8 步，以此类推）：

| 操作 | 行为 |
|---|---|
| 单击 GRID | 选中并保持该步，以便腾出双手弹奏 PADS。再次点按同一步取消选中，点按其他步则转移选区（在 `SELECT MULTI` 模式下每次单击用于增减选步）。 |
| 按住 GRID | 仅在按住期间临时选中该步，同时按住多个 GRID 键可批量编辑。停止播放时按住步进键可试听该步内容。 |
| 按住 PADS + 点按 GRID | 将按住的音符写入该步；若该步已包含其中任意音符，则将其移除。 |
| 选步状态下按 PADS | 在所有已选中步进上添加或移除该键对应的音符（若开启和弦则整组操作）。 |
| 未选步状态下按 PADS | 实时演奏当前轨道（开启 REC 时同步叠录）。 |
| <Key k="ADD" /> / <Key k="SUB" /> | 已选步时调整当前编辑项；未选步时在长 Pattern 中切换上/下一 16 步页。 |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | 已选步时大步调整参数；未选步时切换上/下一个 Pattern。 |
| <Key k="OK" /> | 单击切换 ROLL / STEP（已选步时循环编辑项）；长按 0.45 秒打开 RECORD 面板。 |

音序器不设自动步进光标，未写入音符的步即作为休止符。

横向为当前页的步进（不足 16 步的 Pattern 会自动铺满宽度），纵向由下至上为音高。旋律轨默认覆盖当前八度演奏区可弹奏的所有音（黑键行带底纹），若存在超出该音域的音符则自动扩展显示范围（最多 41 行）；鼓轨按名称列出使用到的鼓声部。音符填充越实代表力度越大，绿色竖线为当前播放头。底部预览格中，点阵表示含音符、白色表示已选中、绿色表示播放头位置。

**写入音符：按住一个或多个演奏区按键，再点按 GRID 上的步进键：**

  <Step keys="hold r3c1~C + G1" shot="seq-hold-tap" at="28,57,15,10">保持按住并点按 GRID 1，即可将 C3 写入第 1 步。</Step>

</Strip>

- **查看单步音符**：单击某步的 GRID 键，该步包含的所有音符会在演奏区全亮显示；再次点按同一步取消选中（见[选中与编辑](#seq-edit)）。
- **实时录音**：开启 REC（<Key k="FN+PLAY" /> 或通过 RECORD 面板），按下 <Key k="PLAY" /> 后直接弹奏演奏区即可叠录（见[播放与实时录音](#seq-transport)）。
- 若该轨音序开关在 TRACK 页被关闭，画面会提示 `SEQUENCE OFF - SEQ > TRACK`。

- **左侧栏**：按音高分行展示当前 16 步页（音域规则与黑键底纹同 ROLL，最多 41 行）。按住的音符高亮对应行，选中的步高亮对应列。
- **右侧栏**：对应演奏区最近按下音符（名称显示于上方）的 4×4 步进网格，点阵密度表示力度，选中步反显。
- 按键逻辑与 ROLL 完全一致（见[音符页的两种视图](#seq-notes)）。不跟节拍逐步行进录入的步骤如下：

  <Step keys="G2, r3c2~D, r3c3~E" shot="seq-step" at="144,25,26,22">单击 GRID 2 锁定选中第 2 步，依次按 D 和 E 将两个音符写入该步；再按一次 E 则将其移除。</Step>
  <Step keys="G2">再次点按 GRID 2 取消选中，或直接点按下一个需要编辑的步。</Step>
</Strip>

- 从演奏区录入的旋律音默认长度为 1 步、力度采用 SETUP KEYS 的 `VELO`；鼓点则采用按下鼓垫所在行的力度。录入后可通过编辑项继续细调（见[选中与编辑](#seq-edit)）。
- 播放时，播放头进入的步会闪绿并保持绿框直至下一步。
- 也可通过 FN 菜单或 RECORD 面板中的 **VIEW** 切换视图。

## 选中与编辑 {#seq-edit}

无论处于 ROLL、STEP 还是鼓机视图，GRID 均支持两种选步方式：

- **短按**（0.25 秒内松开且期间未按其他键）：锁定选中该步以便腾出双手。在默认 **SELECT ONE** 模式下，短按其他步会切换选区，短按当前唯一选中步则取消选中；在 **SELECT MULTI** 模式（于 <Scene name="SETUP" /> <Page name="KEYS" /> 设置，见[KEYS 键盘](./setup.mdx#setup-keys)）下，每次短按可自由增减多个选中步。
- **长按**（按住超过 0.25 秒或期间配合其他按键）：仅在按住期间生效，同时按住多步即可一起编辑。
- 按 <Key k="ESC" /> 清除选区；在 SELECT ONE 模式下翻步进页也会自动清除选区。

<Shot name="seq-selected">
  <Mark at="76,15,14,96">已选中的步进列</Mark>
  <KeyMark keys="G5">选中步：全亮</KeyMark>
  <KeyMark keys="r3c1">该步包含的音符：全亮</KeyMark>
  <KeyMark keys="PADS">其他可发声按键：半亮</KeyMark>
  <Caption>选中第 5 步后，其所在列高亮，该步音符在演奏区全亮显示。</Caption>
</Shot>

选中步进时，其包含的所有音符会在演奏区全亮；播放中未选步时，演奏区会实时同步亮起播放头所在步的音符。

<Strip>
  <Step keys="G5" shot="seq-selected" at="76,15,14,96">单击 GRID 5 选中第 5 步并高亮该列。</Step>
  <Step keys="OK, OK" shot="seq-lane" at="footer">单击 <Key k="OK" /> 循环切换编辑项：**NOTE → LEN → VEL → TIME**，底栏显示当前编辑项与数值。</Step>
  <Step keys="ADD" shot="seq-lane" at="footer">使用 <Key k="ADD" /> / <Key k="SUB" /> 调整数值（支持长按连发），完成后按 <Key k="ESC" /> 取消选中。</Step>
</Strip>

| 按键 | 选步状态下的功能 |
|---|---|
| PADS | 在选中步上添加或移除该键音符（若开启和弦则整组操作：该步只要已含任一和弦音即整体移除）。播放期间编辑不触发实时发声。 |
| <Key k="OK" /> | 循环切换编辑项：**NOTE**（音高）→ **LEN**（时值）→ **VEL**（力度）→ **TIME**（微时间偏移） |
| <Key k="ADD" /> / <Key k="SUB" /> | 调整当前编辑项数值（支持长按连发，按住 <Key k="FN" /> 为大步调整） |
| <Key k="FN+OK" /> | 切换和弦编辑范围：全部音符（`ALL`）或单个指定音符（底栏显示音名） |
| <Key k="ESC" /> | 取消选步（再次按 ESC 才切换场景） |

在鼓轨上，演奏区用于选择不同鼓声部，因此 NOTE 编辑项无法移调（按 ADD / SUB 会提示 `PADS PICK DRUMS`）；LEN、VEL 和 TIME 用法与其他轨道相同。

## DRUMS 鼓机 {#seq-drums}

鼓轨（默认 <Track n="1" />）的 STEP 视图即为鼓机，页签显示为 <Page name="DRUMS" />，且默认以此视图打开。随时可单击 <Key k="OK" /> 切至 ROLL 视图按水平时间轴查看所有激活鼓声部。

  <Mark at="footer">DRUMS 页签</Mark>

- **PADS**：每列对应一种鼓，每行对应打击力度（顶行 127，往下依次 100、70，底行 40）。按下鼓垫即可发声并切换右侧 GRID 显示的鼓声部。
- **按住鼓垫点步进**：按所按行的力度将该鼓写入对应步（已有则移除）；也可先选步再按鼓垫录入。
- **编辑单个鼓点**：选中对应步（短按或按住），按 <Key k="OK" /> 切至 VEL 或 TIME，再用 <Key k="ADD" /> / <Key k="SUB" /> 调整。
- 鼓点力度以四档点阵密度清晰区分（实心、1/2、1/4、1/8）；带微时间偏移的鼓点以细竖条标出在步内的实际位置。
- 按住鼓垫时，对应鼓行会按该力度密度整行高亮，鼓名反显。

<Strip>
  <Step keys="hold r3c3~CH + G1, G3, G5" shot="seq-drums" at="110,14,119,108">按住最下一行的闭镲（CH）并隔步点按 GRID，即可写入轻力度的踩镲。</Step>
  <Step keys="hold G1 + OK, OK, ADD" shot="seq-drum-edit" at="footer">按住第 1 步，连按两次 <Key k="OK" /> 切至 VEL，再按 <Key k="ADD" /> 提高该步力度；松开 G1 即可退出选步。</Step>
</Strip>

- GRID 背光规则与其他音符页一致：有鼓点半亮、选中步全亮、空步灭；按住鼓垫时，包含该鼓的步会全亮。
- 实时录音与 RECORD 面板的用法与其他轨道完全一致。

| GRID 行 | 内容 |
|---|---|
| 第 1 行 | **REC**（实时录音开关）、**SNAP**（导入 take 时对齐整步 `STEPS` 或保留微时间 `FREE`）、**VIEW**（ROLL / STEP 视图切换）；第 4 格留空 |
| 第 2–3 行 | 最近 8 段无感录制缓存（take），按时间倒序排列 |
| 第 4 行 | 预览选中 take 当前小节写入 Pattern 后的排布 |

- 点按第 1 行设置格（或按 <Key k="ADD" /> / <Key k="SUB" />）即可切换状态。
- 点按某段 take 将其选中，用 <Key k="ADD" /> / <Key k="SUB" /> 挑选要导入的小节，然后按 <Key k="OK" /> 写入新 Pattern，或按 <Key k="FN+OK" /> 合并到当前 Pattern。
- GRID 背光：设置与 take 默认半亮，当前焦点以及开启状态的 REC / SNAP 全亮。

## 无感录制：把刚才弹的找回来 {#capture}

<Icon name="capture" /> 即使未开启 REC，你在演奏区弹奏的所有音符都会自动缓存在后台（Capture）。即兴弹到满意的乐句时，可随时将其导入音序器：

<Strip>
  <Step keys="r3c1~C, r3c3~E, r3c5~G" shot="seq-keyboard">自由演奏即可。停顿超过 2.5 秒、切换轨道或连续弹奏满 60 秒会自动切分为新的一段 take。</Step>

- 全部 8 段 take 共用 400 个音符的环形缓存，写满后自动覆盖最早的一段。
- 若 16 个 Pattern 槽位已满，系统会弹出提示，此时可按 <Key k="FN+OK" /> 合并到当前 Pattern。
- 播放期间弹奏的 take 会保留原小节对齐关系；停止状态下弹奏的 take 从第一个音符起按当前 BPM 计时对齐第 1 步。
- 开启 **SNAP**（默认）时，导入的音符会自动量化到最近整步并取整步时值；关闭则完整保留微时间演奏细节。

## 长 Pattern 与翻页 {#seq-long}

单个 Pattern 最长可达 256 步，GRID 与屏幕每次显示其中一页 16 步。页码显示在底栏右侧（如 `2/4`，手动翻页后会变为黄色）。

<Shot name="fn-held">
  <Mark at="cells:3,1-3,2">PAGE − / PAGE +：切换步进页</Mark>
  <Mark at="cells:3,3-3,4">LEN − / LEN +：调整长度</Mark>
  <Caption>在 SEQ 的 FN 菜单中，第 3 行用于翻步进页和调整 Pattern 长度。</Caption>
</Shot>

- **调整长度**：在 TRACK 页调节 **STEPS**（<Key k="ADD" /> / <Key k="SUB" /> 逐增减，<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 按整页边界跳变），或在 FN 菜单中使用 **LEN − / LEN +**（依次为 1、2、4、8、16、32、48……直至 256）。
- **翻步进页**：在音符页未选步时按 <Key k="ADD" /> / <Key k="SUB" />（右侧边条显示 → ←，屏幕弹出 `PAGE n/m`），或在 FN 菜单中使用 **PAGE − / PAGE +**。
- **切换 Pattern**：在音符页未选步时按 <Key k="FN+ADD" /> / <Key k="FN+SUB" /> 切换上/下一个 Pattern（播放期间排队等待本圈结束并提示 `NEXT PATTERN`）。
- 播放期间 GRID 会自动跟随播放头翻页；手动翻页后会锁定在当前页，直到下一次按 PLAY 恢复跟随（选步期间不自动翻页）。
- 新建 Pattern 沿用当前 Pattern 的长度，复制 Pattern 保留原长度。超出长度的步在 GRID 上熄灭。
- 系统仅对包含音符的分页分配内存；若音符内存耗尽，写入将被拒绝并提示 `MEMORY FULL - NOTE NOT WRITTEN`。

## 复制、粘贴、清除、量化 {#seq-tools}

按住 <Key k="FN" /> 配合字母键，或在 FN 菜单中选择 **COPY**、**PASTE**、**CLEAR**、**QUANT**、**DUP**（每项第二行会标明当前作用对象为 `STEPS` 还是 `PATTERN`）。在音符页有选中步时仅作用于选中步；未选步或位于 PATTERN / TRACK 页时则作用于整个 Pattern。

| 快捷键 | 功能 |
|---|---|
| <Key k="FN+C" /> / <Key k="FN+V" /> | 复制 / 粘贴（剪贴板为空时 PASTE 不可用） |
| <Key k="FN+X" /> | 清除（清空整个 Pattern 前会要求确认） |
| <Key k="FN+Q" /> | 将音符量化对齐至整步 |
| <Key k="FN+D" /> | 将当前 Pattern 复制到下一个空槽 |
| <Key k="FN+T" /> | 敲击定速（Tap tempo） |

SEQ 三个子页共用同一套 FN 菜单：

| 行 | 菜单项 |
|---|---|
| 1 | COPY · PASTE · CLEAR · QUANT |
| 2 | DUP · VIEW（ROLL / STEP）· RECORD（RECORD 面板）· SCOPE（<Key k="FN+OK" />，选步时可用） |
| 3 | PAGE − · PAGE +（音符页，长于 16 步时可用）· LEN − · LEN + |
| 4 | SAVE · TAP · REC · SETUP（全界面通用） |

完整菜单说明见[每个画面的菜单](./fn.mdx#fn-menus)。

:::warning

系统不支持撤销操作，因此清空整个 Pattern 前均会弹出确认提示。

:::
