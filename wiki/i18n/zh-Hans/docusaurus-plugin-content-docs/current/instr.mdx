# 1 INSTR 乐器

**INSTR** 控制当前轨道的声音设计，包括音源引擎选择、预设浏览、MIDI 效果（和弦与琶音）、合成参数与轨道效果器。四条轨道各自运行独立引擎，并分别记住上次停留的子页面。

| 音源引擎 | 默认轨道 | 子页面（按 <Key k="CTRL" /> 切换） |
|---|---|---|
| DRUMS（808 鼓机） | <Track n="1" /> | VOICE、KIT、FX |
| JUNO（模拟合成器） | <Track n="2" /> | VOICE、CHORD、ARP、DCO、VCF、ENV、LFO、FX |
| DX7（FM 合成器） | <Track n="3" /> | VOICE、CHORD、ARP、ALGO、LEVELS、OP1–OP6、LFO、FX |
| SAMPLER（采样器） | <Track n="4" /> | VOICE、CHORD、ARP、SAMPLE、TONE、FX |

子页面按音频信号流排序：**VOICE**（音源与预设）→ MIDI 效果（**CHORD**、**ARP**）→ 合成/采样参数页 → 轨道 **FX**。当页签数量超出底部宽度时，两侧显示 `<` `>` 指示并附带右侧「当前页 / 总页数」。随时可按住 <Key k="CTRL" /> 通过页面地图直达目标页。

<Keywords k="乐器, 音源, 合成器, 音色, 引擎, instrument, synth, synthesizer, engine, sound, patch" />

## VOICE：音源和音色 {#instr-voice}

VOICE 是每个引擎的首页，大字显示当前音色名，下方附带实时键盘预览（鼓轨显示八个鼓垫）。

- 按 <Key k="ADD" /> / <Key k="SUB" /> 可直接切换列表中的上/下一个音色并即时试听（ADD 对应列表向上，与浏览器一致）；按住 <Key k="FN" /> 一次跳转 10 个音色。
- 按 <Key k="OK" /> 打开音色浏览器。
- 在 INSTR 任意子页中，FN 菜单均提供 **PRESETS**、**SAVE**、**SAVE AS** 和 **ENGINE**，无需退回 VOICE 即可浏览或保存音色（见[每个画面的菜单](./fn.mdx#fn-menus)）。

切换音源引擎会加载新引擎的默认音色并返回 VOICE 页，该轨原有的 Pattern、和弦和琶音设置保持不变。

<Strip>
  <Step keys="G1" shot="engine-picker" at="cells:2,1-2,4">点按 ENGINE 展开四个音源引擎（当前引擎标注 `NOW`）。在 GRID 上点选（或用 <Key k="ADD" /> / <Key k="SUB" /> + <Key k="OK" />）即可切换，按 <Key k="ESC" /> 取消。</Step>
  <Step keys="ADD" shot="instr-voice" at="8,40,200,26">在 VOICE 页直接按 <Key k="ADD" /> / <Key k="SUB" /> 即可快速切换音色。</Step>
</Strip>

- 如需保留修改，请先通过 FN 菜单的 **SAVE** 或 **SAVE AS** 保存。
- 交互教程运行在临时练习工程中，不会弹出该提示。

## 音色浏览与保存 {#instr-presets}

<Strip>
  <Step keys="G2" shot="preset-browser" at="0,13,240,10">点按 PRESET（或在 VOICE 页按 <Key k="OK" />）打开音色列表，右上角显示当前位置与总数。</Step>
  <Step keys="FN + F, B, A, S, S, OK" shot="preset-filtered" at="0,13,240,10">按 <Key k="FN+F" /> 打开名称过滤，输入关键词（如 `BASS`）后按 <Key k="OK" /> 仅保留匹配项。</Step>
  <Step keys="OK" shot="instr-voice" at="8,40,200,26">用 <Key k="ADD" /> / <Key k="SUB" /> 上下选择，按 <Key k="OK" /> 载入。</Step>
</Strip>

- 在音色列表中，演奏区与 GRID 不响应打字，避免误触过滤；搜索统一使用 <Key k="FN+F" />，提交空内容即可恢复显示全部音色。
- 按一次 <Key k="ESC" /> 清除当前过滤条件，再按一次关闭列表。
- 使用 <Key k="ADD" /> / <Key k="SUB" />（或 <Key k="FN" /> + <Key k=";" /> / <Key k="." />）上下移动，<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 每次翻 8 行。
- **SAVE**（FN 菜单）：若当前为用户自定义音色则直接覆盖保存；若编辑了出厂音色，会自动追加顺延编号保存为新用户音色（如 `LEAD I 2`）。需要自定义名称请使用 **SAVE AS**。用户音色按引擎分类存放在 SD 卡的 `CardenzaSynth/Presets/<音源>/` 目录中。

## 参数页 {#instr-params}

引擎的其余子页（以及 CHORD、ARP 页）均为参数页：**每个 GRID 键对应一个参数**。点按 GRID 键选中参数后，用 <Key k="ADD" /> / <Key k="SUB" /> 调节（支持长按连发，按住 <Key k="FN" /> 大步调节），按 <Key k="FN+OK" />（或 FN 菜单 **RESET**）恢复默认值。开关或枚举型参数可再次点按同一 GRID 键或按 <Key k="OK" /> 切换选项。

  <Mark at="cell:1,2">RESO</Mark>
  <Mark at="cell:1,3">ENV</Mark>

  <KeyMark keys="G1">当前焦点：全亮</KeyMark>
  <KeyMark keys="G2-G6">可调参数：半亮</KeyMark>
  <KeyMark keys="G7-G16">空白格：灭</KeyMark>

参数下方的空白区域会实时绘制对应图形视图（如包络线、滤波曲线、FM 算法拓扑图、波形或示波器）。各参数的完整范围、选项与默认值请查阅下方引擎参考表。

**按住快速选值**：按住 GRID 上任意参数格不放，32 颗演奏区按键会临时映射为该参数的全部取值（数值范围较大时均匀分段），当前值对应按键全亮。按下任意演奏键即可直接跳至对应档位并在底栏弹出数值，松开参数格后演奏区立即恢复正常弹奏。短按仍仅用于聚焦参数。

## CHORD 和 ARP 页 {#instr-midifx}

紧接在 VOICE 之后，每条旋律轨都设有 **CHORD**（单键和弦）与 **ARP**（琶音器）两页。它们绑定在轨道而非单个音色上，因此更换音色或音源引擎时均会保留，并随工程一并存储。鼓轨不含这两页。详细说明见[和弦](./play.mdx#play-chords)与[琶音 ARP](./play.mdx#play-arp)。

<Strip>
  <Step keys="hold CTRL + G2" shot="instr-chord" at="cells:1,1-1,2">CHORD 页用于设置和弦模式与转位，并预览根音和弦及当前调性的各级三和弦。</Step>
  <Step keys="hold CTRL + G3" shot="instr-arp" at="cells:1,1-2,1">ARP 页用于设置模式、RATE、RANGE、GATE 和 HOLD，下方实时显示演奏顺序。</Step>
</Strip>

<Keywords k="和弦页, 琶音页, MIDI 效果, 每轨和弦, 每轨琶音, chord page, arp page, midi fx, midi effects" />

## JUNO 模拟合成器 {#engine-juno}

经典 Juno 风格减法合成架构：DCO 振荡器 → VCF 滤波器 → VCA 包络，并配备 LFO 与合唱效果。

<Strip>
  <Step keys="hold CTRL + G4" shot="instr-juno-dco" at="cells:3,1-4,4">**DCO**：RANGE、SAW、PULSE、PWM、PW SRC、SUB、NOISE、LFO 调制，附实时示波器。</Step>
  <Step keys="CTRL" shot="instr-juno-vcf" at="cells:3,1-4,4">**VCF**：CUTOFF、RESO、ENV、POL、LFO、KBD 键位跟踪，附滤波曲线。</Step>
  <Step keys="CTRL" shot="instr-juno-env" at="cells:3,1-4,4">**ENV**：ADSR 包络、VCA 模式（ENV / GATE）、LEVEL，附包络曲线。</Step>
  <Step keys="CTRL" shot="instr-juno-lfo" at="cells:3,1-4,4">**LFO**：RATE 速率与 DELAY 延迟渐入，附波形预览。</Step>
</Strip>

Juno 预设自带的 Chorus I / II 参数会自动映射到轨道 FX 页的 **CHORUS**。
