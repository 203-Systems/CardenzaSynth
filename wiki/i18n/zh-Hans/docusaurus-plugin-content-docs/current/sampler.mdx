# 采样

<Icon name="sample" /> **SAMPLER** 采样器（默认位于 <Track n="4" />）支持播放 SD 卡中的 WAV 文件或通过内置麦克风现场录制采样。所有鸣片应用共用 SD 卡上的 `CardenzaSynth/Samples` 目录。

**支持格式**：单声道 16 位 PCM WAV，采样率 8–96 kHz，最长 5 分钟。2 秒以内的采样会载入内存以获得最低延迟，更长的音频则直接从 SD 卡流式读取播放。

<Keywords k="采样, 采样器, 麦克风, 录音, 人声, 实地录音, sample, sampling, field recording, sampler, microphone, record audio, wav" />

## 载入采样 {#sampler-load}

<Strip>
  <Step keys="hold TAB + G4, hold CTRL + G4" shot="instr-sampler-sample" at="cell:1,1">在 <Scene name="INSTR" /> 中切换至 <Track n="4" />，按住 <Key k="CTRL" /> 并按 G4 打开 SAMPLE 页。</Step>
  <Step keys="G1" shot="sampler-files" at="0,13,240,10">点按 FILE 打开采样列表，可按 <Key k="FN+F" /> 按文件名筛选。</Step>
  <Step keys="OK" shot="instr-sampler-sample" at="cells:1,3-1,4">用 <Key k="ADD" /> / <Key k="SUB" /> 选择文件，按 <Key k="OK" /> 载入，按 <Key k="ESC" /> 返回。</Step>
</Strip>

在 SAMPLER 轨的任意子页中，FN 菜单也提供 **SAMPLES**（文件列表）、**RECORD**（麦克风录音）和 **PREVIEW**（按原音高试听）快捷入口。载入后即可用演奏区跨音高演奏，其中 **ROOT** 决定按哪个键时以原音高回放。

:::tip

在网页模拟器中，可点击 **Load WAV...** 将电脑本地音频导入共用采样目录（见[存储与采样](./web.mdx#web-storage)）。

:::

## 录一段采样 {#sampler-record}

<Strip>
  <Step keys="G2" shot="sampler-rec" at="8,32,222,34">点按 SAMPLE 页的 REC（或 FN 菜单的 RECORD）进入录音界面。显示 `READY` 后即可录制，单次最长 60 秒。</Step>
  <Step keys="OK" shot="sampler-rec" at="8,72,222,12">按 <Key k="OK" /> 开始录音，再按 <Key k="OK" /> 停止。录音期间屏幕实时显示输入电平。</Step>
</Strip>

- 插入 SD 卡时，音频直接写入 `CardenzaSynth/Session/take-<轨道>.wav` 并约每秒刷盘一次，即使意外断电最多也只损失最后 1 秒。若卡空间已满，录音会自动停止并保留已录内容（`CARD FULL`）。未插卡时仅使用剩余内存，可录制数秒。
- 由于麦克风与扬声器共用硬件时钟引脚，录音期间扬声器会自动静音，音序器在后台照常运行。
- 离开录音界面（切换场景或轨道）或在录音中按 <Key k="ESC" /> 会取消本次录制。
- 未保存的录音可在断电或切换应用后恢复：下次启动鸣片时会自动回到录音界面并提示 `UNSAVED TAKE IS BACK`。

:::warning

未保存的录音受防误删保护：重新录音前会提示 `RECORD AGAIN?`，在裁剪界面按 <Key k="ESC" /> 会提示 `DISCARD TAKE?`（<Key k="OK" /> 确认，<Key k="ESC" /> 取消）。

:::

## 裁剪与试听 {#sampler-trim}

停止录音后会自动进入裁剪界面：

| 按键 | 功能 |
|---|---|
| <Key k="G1" /> / <Key k="G2" />（或 <Key k="OK" />） | 切换起点 / 终点标记（选中项全亮）；使用 <Key k="ADD" /> / <Key k="SUB" /> 移动位置（按住 <Key k="FN" /> 大步移动） |
| <Key k="G3" /> 或 <Key k="PLAY" /> | 试听裁剪后的片段 |
| <Key k="G4" /> | **SAVE**：立即按顺序存为下一个可用编号 `TAKE_nn` 并载入当前轨 |

## 保存、改名与删除 {#sampler-save}

- 裁剪界面第 4 格（SAVE）会将录音保存为 WAV 文件，并自动按序命名为 `TAKE_01`、`TAKE_02`……，无需手动输入文件名。
- 在采样浏览器中按 <Key k="FN+OK" /> 可对光标所在文件执行 **RENAME**（重命名）或 **DELETE**（删除）。删除前会二次确认，确认后将从 SD 卡移除该 WAV 文件。
- 正在被其他轨道引用的采样无法删除（提示 `FILE IN USE`）。
- 采样文件存放在共用 `Samples/` 目录而非嵌入工程文件中，工程仅按文件名引用采样。
