# 工程与存储

一个**工程**完整保存一首歌曲：四条轨道的音源与音色、所有 Pattern、歌曲编排、混音状态（音量、静音、独奏、SEQ 开关）、轨道与总线效果器、BPM 与 Swing、键盘设置，以及各轨道的和弦与琶音器配置。工程存放在 SD 卡上，可在 <Scene name="SETUP" /> 的 PROJECT 和 FILES 页中管理。同时，系统还会在后台自动保存你的当前工作会话（见[工作状态会被保留](#project-session)）。SD 卡是鸣片唯一的数据存储介质，未插卡时所有内容均无法在断电后保留。

| 随工程保存 | 不随工程保存 |
|---|---|
| 音源、音色、采样引用（按文件名）、Pattern、SONG 编排、混音（音量、静音、独奏、SEQ）、轨道与总线效果、BPM、Swing、键盘设置（KEYS）、和弦与琶音器 | `SELECT`（应用级偏好）、设备设置（音量、按键灯、屏幕亮度、日志）、LOOP / SONG 播放模式、REC 待命状态 |

<Keywords k="工程, 存档, 保存, 文件, 项目, 存了什么, project, file, save, storage" />

- 存在未保存改动时，PROJECT 页工程名旁及 FN 菜单的 SAVE 格均会显示 `UNSAVED`。新建或载入其他工程前会弹出确认提示（<Key k="OK" /> 放弃改动，<Key k="ESC" /> 取消）。
- PROJECT 与 FILES 页的 FN 菜单均提供 **NEW**、**LOAD** 与 **SAVE AS**（见[PROJECT 工程](./setup.mdx#setup-project)与[FILES 工程文件](./setup.mdx#setup-files)）。
- **NEW** 会初始化默认四轨（<Track n="1" /> <Track n="2" /> <Track n="3" /> <Track n="4" />）与默认演奏设置（C 大调、关闭和弦与琶音器）。
- 常见保存报错（显示在底栏）：`NO SD CARD`（开机未检测到卡）、`SD CARD ERROR`（写入失败）、`SAVE SAMPLE FIRST`（有未保存的麦克风采样）或 `NO MEMORY`。常见载入报错：`INVALID PROJECT`、`SAMPLE MISSING`（引用采样不在 `Samples/` 目录中）或 `NO MEMORY`。
- 工程采用纯文本格式（`.ccproj`，格式 v7），向下兼容读取 v1–v6（v6 之前的旧文件不含键盘、和弦与琶音数据，加载时保持当前设置）。0.1.0 版固件仅支持读取 v1–v6，无法打开 v7 工程。由于工程按文件名引用采样，在卡上重命名或删除采样会影响所有引用它的工程。
- 保存过程采用原子写入：先写入临时文件再替换目标文件，防止保存瞬间断电导致工程损坏。

## 工作状态会被保留 {#project-session}

只要插入了 SD 卡，随时关机或直接拔电都不会丢失当前进度：系统会自动在后台保存你的工作会话，并在下次开机时完整恢复。

- 会话自动保存包含工程内的全部内容，以及当前工程名与 `UNSAVED` 状态（因此重启后切换其他工程依然会提醒保存）。恢复后默认停留在 T1。
- 停止按键 1.5 秒且无按键按住时自动写入（播放或停止状态均可触发）；持续操作或正在从卡流式播放采样时，最多间隔 60 秒写入一次。写入在后台异步执行，不会卡顿音频或界面，未产生改动的按键不会触发写入。切换至其他应用时会立即刷盘保存。
- 自动保存仅用于临时会话恢复，不等同于命名存档。长期保留的作品或切换工程前，仍请按 <Key k="FN+S" /> 正式保存。
- 若写入失败，屏幕会提示 `AUTOSAVE FAILED: SD CARD ERROR`（拔卡时为 `NO SD CARD`）并持续重试，待 SD 卡恢复响应后自动补写。
- 未保存的采样录音会暂存在 `Session/take-<轨道>.wav`，重启后自动恢复并提示 `UNSAVED TAKE IS BACK`。若会话引用的采样暂时读取不到，插回或恢复 SD 卡后会自动重新加载。
- 若设备连续三次启动失败，下一次启动将自动跳过一次会话恢复作为保护机制。
- 自动保存不包含无感录制的 take 缓存以及播放/停止状态。未插卡时不会保留任何会话（见[没插卡或卡坏了](#storage-card)）。

:::tip

设备与应用偏好设置（SELECT、主音量、按键灯亮度、屏幕亮度、日志开关）在修改约 1 秒后即会自动写入 SD 卡，无需手动保存。

:::

## SD 卡上的目录 {#storage-layout}

鸣片的全部数据统一存放在 SD 卡根目录的 `CardenzaSynth` 文件夹中：

```text
<SD 卡>/CardenzaSynth/
  Settings/system.cfg      设备级设置（音量、按键灯、屏幕亮度、日志）
  Settings/synth.cfg       应用偏好（SELECT）
  Projects/                已保存的工程（.ccproj）
  Presets/<音源>/           用户自定义音色
  Samples/                 WAV 采样（所有应用共用）
  Session/                 自动保存的会话与未保存的录音
  Logs/                    诊断日志（log.txt）
  Apps/<作者>/<名字>/       其他第三方固件应用的独立目录
```

- 该目录结构与 0.1.0 版本一致，原有工程、音色与采样可直接沿用。
- 早期开发版的旧目录（如 `Cardenza/` 或 0.1.0 之前的单数命名 `Project`、`Preset`、`Sample`）不会被读取或修改；如需迁移，可在电脑上将文件直接复制到上述目录（文件格式完全兼容）。
- 每个应用仅读写自身目录及共用的 `Samples/` 目录。

## 设置文件 {#storage-settings}

`Settings/` 中的 `.cfg` 文件均为纯文本 `key=value` 配置，可在电脑上直接查看或编辑：

```text
# Cardenza settings: Cardenza/Synth (storage protocol 2)
keys.select=1
```

配置解析器具备容错能力，会自动忽略损坏行并保留无法识别的字段，方便新旧版本固件共用同一张 SD 卡。设备写入改动前会先重新读取原文件，仅更新设备上变动过的键值，不会覆盖你在电脑上手动添加或修改的配置。

<Keywords k="设置文件, 配置, 文本, settings file, config, cfg" />

## 日志 {#storage-log}

当 <Scene name="SETUP" /> <Page name="SYSTEM" /> 的 **LOG** 开启（默认开启）且插有 SD 卡时，鸣片会将每次开机的固件版本、文件读写记录、错误提示及崩溃报告写入 `CardenzaSynth/Logs/log.txt`。文件超过 512 KB 后自动轮转为 `log.1.txt` 并创建新的 `log.txt`。

若遇到死机、声音异常或保存失败等问题，反馈时附带这两个日志文件及简要复现步骤即可帮助排查。关闭 **LOG** 后不再写入任何日志。

## 没插卡或卡坏了 {#storage-card}

  <Mark at="cells:1,1-1,4">VOLUME、KEY LED、SCREEN、LOG</Mark>

鸣片仅在开机时检测一次 SD 卡：

- **开机未插卡**：开机动画后会提示 `NO SD CARD, NOTHING WILL BE SAVED, INSERT A CARD AND RESTART TO SAVE`（按 <Key k="OK" /> 或 <Key k="ESC" /> 关闭）。本次运行期间不会挂载中途插入的卡：你仍可正常演奏与调参，但断电后所有改动都会丢失，保存会报错 `NO SD CARD`，FILES 列表为空，且无法启动交互式 USB 教程。请先插入 SD 卡并重启设备。
- **运行中 SD 卡失去响应**：失败的操作会提示 `SD CARD ERROR`，系统同时尝试重新检测；待卡恢复响应后，设置与会话自动保存会自动补写。
- 可随时在 <Scene name="SETUP" /> <Page name="SYSTEM" /> 查看当前卡状态（`SD CARD READY` 或 `NOT FOUND`）。
