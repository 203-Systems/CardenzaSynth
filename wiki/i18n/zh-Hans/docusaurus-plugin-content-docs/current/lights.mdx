# 按键灯

每颗按键均配有单色背光 LED，用来指示该键在当前页面中的角色与状态。灯光共有三种常亮亮度与一种闪烁状态：

| 灯光 | 状态 | 含义 |
|---|---|---|
| <Led state="off" /> | **灭** | 无效或空槽 |
| <Led state="half" /> | **半亮** | 可用或有内容，但未选中 |
| <Led state="full" /> | **全亮** | 已选中、已启用或正在发声 |
| <Led state="blink" /> | **闪烁** | 等待切换或等待确认 |

<Keywords k="灯, 灯光, 指示灯, 背光, led, lights, key lights, backlight" />

| 状态 | 含义 | 常见示例 |
|---|---|---|
| <Led state="off">灭</Led> | 无效或空置 | 空步、不可发声键（钢琴空位、被静音的音阶外音）、当前画面不可用的菜单项、已关闭的发送 |
| <Led state="half">半亮</Led> | 可用或已存在 | 含音符的步、可发声琴键、可调参数、可用菜单项、已创建的 Pattern |
| <Led state="full">全亮</Led> | 选中或激活中 | 已选中步进、焦点参数、当前场景/轨道/页面/Pattern、按下或发声中的琴键、播放头、开启状态的开关（静音、独奏、音序开） |
| <Led state="blink">闪烁</Led> | 等待状态 | 排队等待切换的 Pattern、待切入的 SONG 段落、确认框中的 OK 键、录音待命时的 PLAY 键 |

:::note

物理按键硬件支持 16 级经伽马校正的 PWM 调光（整体亮度由 **KEY LED** 缩放）。界面固定采用三档状态：灭、「半亮」（最低可见微光，1/15 占空比）与「全亮」（100%），不使用中间档位，且动画不会误点亮本应熄灭的键。左右两侧 8 颗边缘键的物理亮度上限为半亮，其全亮状态同步显示在屏幕左右边条上（见[屏幕两侧和按键灯同步](#lights-edges)）。

:::

| 页面 | GRID 背光规则 |
|---|---|
| SEQ 音符页（ROLL、STEP、鼓机） | 空步灭，含音符半亮，选中步全亮，播放头全亮，超出 Pattern 长度的步灭；未选步时按住 PADS，包含对应音符的步会全亮。 |
| SEQ PATTERN | 已有 Pattern 半亮，当前激活全亮，排队中闪烁；NEW 与空槽灭。 |
| SEQ TRACK | 四项设置半亮，焦点全亮。 |
| RECORD 面板 | 设置与 take 半亮，当前焦点及开启状态的 REC / SNAP 全亮。 |
| INSTR 参数页（含 CHORD、ARP） | 参数与操作项半亮，焦点参数（及开启状态的 HOLD）全亮，空格灭。 |
| TAPE SESSION | 每轨当前 Pattern 全亮，其余半亮，排队中闪烁。 |
| TAPE SONG | 含 Pattern 的格子半亮，`--` 灭，选中格与正在播放的段落全亮，待切入段落闪烁。 |
| TAPE MIX | 选中轨全亮；静音、独奏、音序开关开启全亮，关闭半亮。 |
| TAPE SENDS / FX | 开启的发送半亮、关闭灭、焦点全亮；总线 FX 参数半亮、焦点全亮。 |
| SETUP PROJECT | 操作项半亮，焦点 BPM / SWING 全亮，SONG 模式下 PLAY 全亮。 |
| SETUP FILES | 全灭（使用 ADD / SUB 浏览）。 |
| SETUP KEYS / SYSTEM | 设置项半亮，焦点全亮（聚焦 KEY LED 时演奏区切换为亮度测试梯）。 |
| 按住 ESC | 四列对应四个场景：当前场景全亮，其余半亮（第 1 列为 SETUP）；演奏区全灭。 |
| 按住 TAB / CTRL | 地图可选项半亮，当前项全亮；演奏区全灭。 |
| 按住 FN / FN 菜单 | 可用项半亮，开启中的开关全亮，不可用项与空位灭。 |
| 按住参数格 | 演奏区显示可选档位（半亮），当前值全亮。 |
| 文字输入 | 字符键、退格、OK 与空格半亮。 |

- **演奏区 PADS**：实时反映当前轨键盘布局。可发声按键半亮；按下的键、和弦组成音、ARP 音符及音序器回放音符全亮；不可发声键熄灭（见[键盘排列](./play.mdx#play-keyboard)）。在 SEQ 页面中，演奏区还会全亮显示当前选中步（或播放时当前播放步）的音符。
- **鼓轨**：三档亮度规则的唯一例外。待机时鼓垫半亮，按住时该列从底行亮至所按行，触发打击时灯光随力度大小向上扩散；屏幕鼓垫则以四档点阵密度表现力度。
- **左侧四键**：ESC、TAB、FN 常驻半亮（多页场景中 CTRL 半亮）；按住时全亮；常驻打开 FN 菜单时 FN 全亮，TAB 与 CTRL 熄灭（与其他弹窗一致）。切轨后片刻，仅新轨所在行的左侧键会短暂亮起（T1 = ESC 行至 T4 = CTRL 行）。
- **右侧四键**：有可调内容时 ADD / SUB 半亮；OK 具备动作时半亮（在 SEQ STEP 视图全亮）；PLAY 停止时半亮、播放时全亮、录音待命时闪烁。

按住 <Key k="FN" /> 时，整块键盘会亮起当前页面所有可用的 FN 功能键：

| 区域 | 按住 FN 时的灯光状态 |
|---|---|
| GRID | 可用菜单项 <Led state="half">半亮</Led>，开启的开关 <Led state="full">全亮</Led>，不可用项与空位 <Led state="off">灭</Led> |
| 演奏区 PADS | 当前页可用的菜单字母键（<Key k="C" /> <Key k="V" /> <Key k="X" /> <Key k="Q" /> <Key k="D" />、<Key k="S" /> <Key k="T" />）及快捷调节键（<Key k="6" /> <Key k="7" /> <Key k="8" /> <Key k="Y" /> <Key k="U" /> <Key k="I" />）半亮，其余全灭 |
| <Key k="ESC" /> <Key k="TAB" /> <Key k="CTRL" /> | ESC、TAB 半亮；多页场景下 CTRL 半亮 |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> <Key k="PLAY" /> | ADD / SUB 半亮；存在 <Key k="FN+OK" /> 功能时 OK 半亮；PLAY 半亮（录音待命时全亮） |

## 屏幕两侧和按键灯同步 {#lights-edges}

屏幕左右边缘的 4 + 4 条边条直接同步映射机身两侧 8 颗边缘按键的实时状态。由于这 8 颗物理按键最高仅亮至半亮，其全亮状态会通过屏幕边条清晰呈现。

  <Mark at="strip:FN">FN 边条</Mark>

  <Mark at="strip:PLAY">PLAY</Mark>
  <KeyMark keys="TAB">新轨道对应行</KeyMark>
  <KeyMark keys="ESC FN CTRL">灭</KeyMark>
  <Caption>按 TAB 切换至 T2 瞬间：左侧仅第 2 颗键短暂亮起，对应屏幕边条变为实色。</Caption>
</Shot>

| 按键灯状态 | 屏幕边条表现 |
|---|---|
| <Led state="off">灭</Led> | 极淡显示 |
| <Led state="half">半亮</Led> | 30% 点阵填充 |
| <Led state="full">全亮</Led> | 实色填充（右侧图标反白为黑色） |

长按、切轨提示、地图与闪烁状态在物理按键和屏幕边条间始终同步。右侧边条还会随页面切换 ADD / SUB 图标（▲ ▼ 表示调值与列表，→ ← 表示横向翻页，文字输入时显示删除图标），PLAY 边条在播放时呈绿色、录音待命时呈红色。

:::tip

连续 4 秒无按键操作后，系统每隔 10 秒会在两侧运行一次柔光扫描，同步渐亮渐暗每行对应的物理边缘键与屏幕边条。

:::
