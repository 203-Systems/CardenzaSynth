# 演奏

演奏区（PADS）始终用于演奏当前激活的轨道。键盘排列、音阶、根音、八度、力度与音阶锁定为四条轨道共用，位于 <Scene name="SETUP" /> 的 **KEYS** 页（见[KEYS 键盘](./setup.mdx#setup-keys)）。和弦与琶音（ARP）按轨道独立配置，每条旋律轨在 <Scene name="INSTR" /> 中均配有专属的 **CHORD** 和 **ARP** 页。这些设置均随工程保存；新建工程（NEW）默认恢复为 PIANO 排列、C 大调、关闭和弦与琶音。

## 键盘排列 {#play-keyboard}

旋律轨提供三种键盘排列模式（在 KEYS 页通过 LAYOUT 切换），按键背光会直观标出可发声的键位：

<Shot name="seq-keyboard">
  <KeyMark keys="r0c2 r0c3 r0c5 r0c6 r0c7">黑键（高八度）</KeyMark>
  <KeyMark keys="r1c1-r1c8">白键 C–C（高八度）</KeyMark>
  <KeyMark keys="r2c2 r2c3 r2c5 r2c6 r2c7">黑键（低八度）</KeyMark>
  <KeyMark keys="r3c1-r3c8">白键 C–C（左下角为 C3）</KeyMark>
  <KeyMark keys="r0c1 r0c4 r0c8 r2c1 r2c4 r2c8">无键空位：灭</KeyMark>
  <Caption>默认 PIANO 钢琴排列：两行构成一个八度，黑键在上、白键在下，无黑键的空位熄灭且不发声。</Caption>
</Shot>

| 排列模式 | 键位映射 | 灯光状态 |
|---|---|---|
| **PIANO 钢琴**（默认） | 两个完整八度：下方两行从左下角 C3 起，上方两行高一个八度；每组下排为白键 C D E F G A B C，上排为黑键。无黑键空位（C# 前、E–F 间、A# 后）不发声。 | 空位 <Led state="off" /> |
| **SCALE 音阶** | 仅排布当前音阶内的音符，从根音起自左向右依次升高，每往上一行升高一个八度，任意按键均在调内。 | 全部 <Led state="half" /> |
| **CHROMA 半音** | 从根音起按半音依次排列，自左向右、自下而上每键升高一个半音。 | 全部 <Led state="half" /> |

<Strip>
  <Step keys="G1" shot="keys-scale" at="cell:1,1">在 SETUP KEYS 页点按 LAYOUT 切换排列。SCALE 模式下每个按键都在当前音阶内。</Step>
  <Step keys="G1" shot="keys-chroma" at="cell:1,1">再次点按切换为 CHROMA，每键递增一个半音。</Step>
  <Step keys="G1" shot="setup-keys" at="cell:1,1">再次点按切回 PIANO。</Step>
</Strip>

| 按键灯 | 演奏区含义 |
|---|---|
| <Led state="half">半亮</Led> | 可正常发声的键 |
| <Led state="full">全亮</Led> | 当前按下的键、和弦生成的组成音、ARP 正在触发的音，或音序器正在本轨播放的音 |
| <Led state="off">灭</Led> | 不可发声（钢琴空位或被锁定的音阶外音） |

## 八度 {#play-octave}

KEYS 页的 **OCTAVE**（−3 到 +3）用于整体升降键盘音域。在任意界面也可使用快捷组合键调整：

<Strip>
  <Step keys="hold FN + 8" shot="fn-octave" at="14,94,212,28">按住 <Key k="FN" /> 并按 <Key k="8" /> 升八度、按 <Key k="I" /> 降八度（按住可连发），屏幕底部会弹出当前八度值。</Step>
  <Step keys="G4" shot="setup-keys" at="cell:1,4">或在 SETUP KEYS 页点选 OCTAVE（GRID 4），使用 <Key k="ADD" /> / <Key k="SUB" /> 调节。</Step>
</Strip>

<Keywords k="八度, 移调, 升高, 降低, 高音, 低音, octave, transpose, shift, higher, lower" />

## 力度 {#play-velocity}

机身按键不支持力度感应。旋律轨所有按键均使用 KEYS 页设定的固定力度 **VELO**（1–127，默认 110）。实时录制的音符会沿用该值，后续可在音序器音符页的 VEL 编辑项中逐一修改（见[选中与编辑](./seq.mdx#seq-edit)）。鼓轨不使用 VELO，而是通过按键所在行来指定打击力度（见[鼓](#play-drums)）。

<Keywords k="力度, 轻重, 音量大小, velocity, dynamics, how hard" />

## 音阶锁定 LOCK {#play-lock}

在 PIANO 和 CHROMA 排列下，**LOCK** 决定按下音阶外琴键时的行为：

| LOCK | 音阶外琴键行为 | 灯光 |
|---|---|---|
| **OFF** | 正常发声 | <Led state="half" /> |
| **MUTE** | 静音 | <Led state="off" /> |
| **SNAP** | 自动吸附到下方最近的音阶音 | <Led state="half" /> |

<Keywords k="锁定, 音阶锁定, 防错音, 吸附, lock, scale lock, snap, mute, wrong notes" />

## 和弦 {#play-chords}

<Scene name="INSTR" /> 中的 **CHORD** 页支持单键触发完整和弦。和弦设置归属轨道本身，切换音色或音源引擎时均会保留。鼓轨不含 CHORD 页。

<Strip>
  <Step keys="hold CTRL + G2" shot="instr-chord" at="cell:1,1">在 <Scene name="INSTR" /> 中按住 <Key k="CTRL" /> 并按 G2 打开 CHORD 页（默认关闭）。</Step>
  <Step keys="G1" shot="chord-on" at="cell:1,1 9,43,170,20">点按 CHORD 切换为 TRIAD，屏幕会显示根音按键触发的组成音（如 `C3 PLAYS C3 E3 G3`）。</Step>
  <Step keys="hold r3c1~C" shot="chord-held" at="cells:3,1-4,4">按下琴键即可同时奏响三个和弦音，所有组成音会在屏幕与演奏区同步点亮。</Step>
</Strip>

- **CHORD**：可选 OFF、TRIAD、7TH、MAJ、MIN、SUS4、MAJ7、MIN7、DOM7、POWER、OCTAVE。其中 TRIAD 和 7TH 按当前音阶顺阶叠置三度（音阶外按键默认使用大三或属七和弦），其余模式均为固定和弦结构。
- **VOICING**：可选 ROOT（原位）、INV1（第一转位：最低音升八度）、INV2（第二转位：最低两音升八度）和 SPREAD（展开排列：第二音升八度）。
- 屏幕第二行会列出当前调性各音级对应的顺阶三和弦（受限于全大写字体，小三和弦记为 `D-`，减三和弦记为 `BDIM`）。
- 实时录音时，和弦组成音会作为独立音符写入；开启 ARP 时会逐音分解演奏。在 SEQ 音符页编辑步进时，按下一个琴键会将整个和弦作为整体添加或移除（见[选中与编辑](./seq.mdx#seq-edit)）。

## 琶音 ARP {#play-arp}

<Scene name="INSTR" /> 中的 **ARP** 页可将按住的音符按设定节拍依次分解演奏。每条旋律轨均拥有独立的琶音器，并可多轨同时运行（例如在 T2 上开启 HOLD 锁定琶音，再切到 T3 演奏其他声部）。

<Strip>
  <Step keys="hold CTRL + G3" shot="instr-arp" at="cell:1,1">在 <Scene name="INSTR" /> 中按住 <Key k="CTRL" /> 并按 G3 打开 ARP 页。ARP 关闭时下方步进预览呈暗色。</Step>
  <Step keys="G1, hold r3c1~C + r3c3~E + r3c5~G" shot="arp-running" at="cells:3,1-4,4">点按 ARP 切换为 UP，按住 C、E、G 即可由低到高依次循环琶音。</Step>
</Strip>

<Shot name="arp-running">
  <Mark at="cell:1,1">ARP 模式</Mark>
  <Mark at="cell:1,2">RATE 速率</Mark>
  <Mark at="cell:1,3">RANGE 八度范围</Mark>
  <Mark at="cell:1,4">GATE 门限时长</Mark>
  <Mark at="cell:2,1">HOLD 保持（松手继续）</Mark>
  <Mark at="cells:3,1-4,4">16 步演奏顺序预览</Mark>
  <KeyMark keys="r3c1 r3c3 r3c5">按住的键</KeyMark>
  <Caption>ARP UP 模式下按住 C、E、G：每根竖条代表一步的音高与 GATE 时长，白色条为当前正在发声的步。</Caption>
</Shot>

| 参数 | 选项说明 |
|---|---|
| ARP | OFF、UP、DOWN、UP-DN、RANDOM、ORDER（按按键顺序） |
| RATE | 1/4、1/8、1/8T、1/16（默认）、1/16T、1/32 |
| RANGE | 1–4 个八度（向上扩展） |
| GATE | 10–100%（每个音占步长的比例，默认 50%） |
| HOLD | 松手后继续保持琶音；全部松开后再按新键即替换为新音组。点按该格可直接开关，无需先聚焦。 |

- 最多支持同时琶音 16 个音符（包含和弦生成的组成音），按下瞬间立即触发首音。
- 停止播放时按当前 BPM 自由运行；播放时自动同步至音序器节拍（1/16 速率跟随全局 Swing），启停播放不会打断琶音相位。
- UP、DOWN 和 UP-DN 模式在高低折返点不重复发声。
- 播放且开启 REC 实时录音时，ARP 输出的音符会按当前 GATE 长度直接录进该轨 Pattern。
- 切换轨道不会中断其他轨道的琶音。关闭 HOLD 会立即停止保持的音符（仅保留仍按住的键）。按 <Key k="FN+ESC" />（全部停止）或载入工程会停止所有轨道的 ARP。

## 鼓 {#play-drums}

在鼓轨（默认 <Track n="1" />）上，演奏区每一**列**对应一种鼓，每一**行**对应不同力度：最上方一行力度 127，往下依次为 100、70，最下方一行力度 40。待机时所有鼓垫半亮；按住某键时该列自下而上亮至当前行，触发鼓点时灯光会按力度大小向上扩散。屏幕上通过四档点阵密度区分力度。鼓轨不使用音阶、和弦、VELO 和 ARP，各鼓声部的音量可在 INSTR KIT 页单独调节（见[DRUMS 鼓机](./instr.mdx#engine-drums)）。
