## 全部按键速查 {#ref-shortcuts}

**导航与走带按键**

| 按键 | 功能 |
|---|---|
| <Key k="ESC" /> 单击 | 循环切换场景（`1 INSTR → 2 SEQ → 3 TAPE`）；退出 SETUP；取消弹窗；在 SEQ 中清除选步 |
| <Key k="hold ESC" /> + <Key k="GRID" /> | 展开场景地图（`0 SETUP`、`1 INSTR`、`2 SEQ`、`3 TAPE`），第 1 列进入 SETUP |
| <Key k="TAB" /> 单击 | 下一轨 |
| <Key k="hold TAB" /> + <Key k="GRID" /> | 展开轨道地图（同 MIX 布局：选轨、静音、独奏、音序开关） |
| <Key k="TAB" /> + <Key k="ADD" /> / <Key k="SUB" /> | 下一轨 / 上一轨 |
| <Key k="CTRL" /> 单击 | 下一页 |
| <Key k="hold CTRL" /> + <Key k="GRID" /> | 展开当前场景页面地图，点按直达任意页面 |
| <Key k="CTRL" /> + <Key k="ADD" /> / <Key k="SUB" /> | 下一页 / 上一页 |
| <Key k="FN" /> 单击 | 常驻打开或关闭当前页面的 FN 菜单（点按 GRID 执行后关闭） |
| <Key k="hold FN" /> | 按住期间显示 FN 菜单并激活全键盘第二功能 |
| <Key k="ADD" /> / <Key k="SUB" /> | 增减数值或在列表中上下移动（长按连发加速）；SEQ 音符页未选步时翻 16 步页 |
| SEQ 音符页的 <Key k="GRID" /> | 单击锁定选步（再点取消）；按住临时选步；按住 PADS 点按 GRID 添加或移除音符 |
| <Key k="OK" /> | 确认、进入或切换；SEQ 音符页单击切换 ROLL / STEP、长按打开 RECORD 面板，选步时循环 `NOTE → LEN → VEL → TIME` |
| <Key k="PLAY" /> | 播放 / 停止 |
| HOME 侧键 | 打开系统菜单（返回启动器、重新启动、关机、下载模式；Cardenza Synth 0.2.1 起） |
| 按住 GRID 参数格 | 将该参数的全部取值映射至 32 颗演奏区按键以便直选 |

**FN 组合快捷键**

| 按键 | 功能 |
|---|---|
| <Key k="FN+GRID" /> | 执行对应 FN 菜单项 |
| <Key k="FN" /> + <Key k="6" /> / <Key k="Y" /> | BPM + / −（全局生效，支持长按连发） |
| <Key k="FN" /> + <Key k="7" /> / <Key k="U" /> | 主音量 + / − |
| <Key k="FN" /> + <Key k="8" /> / <Key k="I" /> | 八度 + / − |
| <Key k="FN+ESC" /> | 全部停止：停止音序器、全部 ARP 与所有发声 |
| <Key k="FN+TAB" /> | 上一轨 |
| <Key k="FN+CTRL" /> | 上一页 |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | 大步调节（BPM ±10、SETUP 设置 ±5）；SEQ 音符页未选步时切换上/下一个 Pattern；列表按页翻动 |
| <Key k="FN+OK" /> | 页面第二 OK：RESET 恢复默认、SCOPE 切换和弦编辑范围（SEQ）、ADD TO SONG（SESSION）、SONG / LOOP 切换（SONG）、合并 take（RECORD 面板）、重命名/删除（采样列表） |
| <Key k="FN+PLAY" /> | 开关实时录音待命（REC） |
| <Key k="FN+C" /> / <Key k="FN+V" /> | 复制 / 粘贴（选中的步、Pattern 或 SONG 段落） |
| <Key k="FN+X" /> | 清除步进/Pattern（清空整段需确认），或删除 SONG 段落 |
| <Key k="FN+Q" /> | 将选中步或整个 Pattern 量化对齐至整步 |
| <Key k="FN+D" /> | 复制当前 Pattern 或 SONG 段落 |
| <Key k="FN+T" /> | 敲击定速（Tap tempo） |
| <Key k="FN+S" /> | 保存工程（未命名工程自动保存为 `SONG 01`、`SONG 02`……） |

|---|---|

| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | 向上 / 向下翻页 |
| <Key k="ADD~del" /> / <Key k="FN" /> + <Key k="ADD~del" /> | 文字输入中退格删除 / 向后删除 |
| <Key k="OK" /> / <Key k="ESC" /> | 确定 / 取消 |

## 名词解释 {#glossary}

| 名词 | 说明 |
|---|---|
| 轨道 Track | 四个独立声部通道（T1–T4），各配备独立引擎、Pattern、和弦与琶音器 |
| 音源 Engine | 分配给轨道的发声合成器：DRUMS、JUNO、DX7 或 SAMPLER |
| 音色 Preset / Sound | 音源的一组已保存参数配置 |
| 步 Step | 音序器最小时间格（1/16 音符） |
| 微步 Microstep | 单步内的 6 等分细分，用于记录非严格对齐网格的演奏时间 |
| Pattern | 1 至 256 步的音序片段（每页显示 16 步），每轨最多 16 个 |
| 编排行 / 段落 Song row | SONG 模式中的单个段落，指定各轨播放的 Pattern 与小节数（SONG 页中为一列，FN 菜单写作 `ROW n`） |
| 场景 Scene | 界面的四个顶层视图：0 SETUP、1 INSTR、2 SEQ、3 TAPE |
| SETUP | 0 号场景，集中管理工程与全局键盘/设备设置（按住 ESC + GRID 第 1 列进入） |
| FN 菜单 | 按住或单击 FN 时在 GRID 上展开的当前页面快捷菜单 |
| Take | 后台无感录制自动缓存的一段演奏乐句 |
| 自动保存 Autosave | 后台写入 SD 卡的工作会话快照，确保随时断电不丢进度 |
| GRID | 右侧 4×4 按键阵列，与屏幕中央 4×4 网格一一对应 |
| PADS 演奏区 | 中间 4×8 按键区，用于实时演奏当前轨道 |
| 发送 Send | 从单轨送往共用总线延迟或混响的信号电平 |
| 总线 Master bus | 四轨混音后统一经过的母带效果链（EQ、压缩、磁带饱和） |
