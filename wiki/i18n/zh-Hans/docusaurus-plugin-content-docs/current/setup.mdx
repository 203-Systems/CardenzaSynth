# 0 SETUP 设置

**SETUP**（0 号场景）独立于常规的 <Key k="ESC" /> 场景循环之外，集中管理工程文件、四轨共用键盘设置与设备系统设置。按 <Key k="CTRL" /> 在四个子页面间切换（按住 <Key k="CTRL" /> 可查看页面地图）：

<Page name="PROJECT" /> <Page name="FILES" /> <Page name="KEYS" /> <Page name="SYSTEM" />

| 页面 | 作用范围 | 存储位置 |
|---|---|---|
| PROJECT、FILES | 当前工程与已保存的工程列表 | SD 卡工程文件（含 BPM 与 Swing） |
| KEYS | 四轨共用键盘设置 | 随工程保存（`SELECT` 除外，为全局应用偏好） |
| SYSTEM | 硬件与设备级设置 | 所有鸣片应用共用，独立于工程 |

和弦与琶音器为分轨设置，位于 <Scene name="INSTR" /> 的 **CHORD** 和 **ARP** 页（见[和弦和琶音](#setup-chord-arp)）。

## 进出 SETUP {#setup-open}

<Strip>
  <Step keys="hold ESC" shot="map-esc" at="cells:1,1-4,1">按住 <Key k="ESC" /> 展开场景地图，第 1 列即为 **0 SETUP**（带虚线边框与暗色编号）。</Step>
  <Step keys="hold ESC + G1" shot="setup-project" at="8,0,41,11">按第 1 列任意键即可进入 SETUP，并停在上次离开的子页面。</Step>
  <Step keys="ESC" shot="instr-voice" at="scene">在 SETUP 中单击 <Key k="ESC" /> 即可返回原场景（本例中为 INSTR）。</Step>
</Strip>

- 单击 <Key k="ESC" /> 只在 1 INSTR → 2 SEQ → 3 TAPE 之间循环，不会进入 SETUP（见[场景：ESC](./navigate.mdx#nav-scenes)）。
- 也可通过任意画面 FN 菜单右下角的 **SETUP** 格进入（见[每个画面的菜单](./fn.mdx#fn-menus)）；进入 SETUP 后，同一位置会显示 **BACK** 用于返回原场景。
- 在 SETUP 中演奏区保持可用，方便随时试听键盘或音量调整效果。

  <KeyMark keys="G1-G3 G7">操作项：半亮</KeyMark>
  <KeyMark keys="G5">焦点：全亮</KeyMark>
  <KeyMark keys="G6 G8">SWING 与 PLAY（SONG 模式下 PLAY 全亮）</KeyMark>
  <Caption>SETUP PROJECT 页面：工程操作、速度与播放模式、工程状态及四轨摘要。</Caption>
</Shot>

| GRID 行 | 功能 |
|---|---|
| 第 1 行 | **SAVE**（立即保存）、**LOAD**（跳转 FILES）、**NEW**（新建默认四轨工程；存在未保存改动时会先确认） |
| 第 2 行 | **BPM**（30–300）与 **SWING**（50–75%）：点选后用 <Key k="ADD" /> / <Key k="SUB" /> 调节；**TAP**：按节奏连点设定 BPM；**PLAY**：切换 LOOP / SONG 播放模式（SONG 时全亮，见[SONG：编排整首歌](./tape.mdx#tape-song)）。 |

- 按 <Key k="OK" /> 直接保存工程；若当前焦点在 **TAP** 上，按 <Key k="OK" /> 则执行敲击定速。
- 按住 <Key k="FN" /> 配合 <Key k="ADD" /> / <Key k="SUB" /> 可大步调节（BPM ±10，Swing ±5）。按住 **BPM** 或 **SWING** 格不放，32 颗演奏键会映射其完整范围（左上最小、右下最大），点按即可直达目标值。
- 未命名工程点击 SAVE 时会自动按序命名为 `SONG 01`、`SONG 02`……；如需自定义名称（最多 24 个字符，支持字母、数字、空格与 `-`），请使用 FN 菜单中的 **SAVE AS**（见[输入文字](./fn.mdx#fn-text)）。若目标名称已存在，覆盖前会要求确认（<Key k="OK" /> 确认，<Key k="ESC" /> 取消）。
- **NEW** 会创建默认四轨工程（C 大调、关闭和弦与全部琶音器），`SELECT` 偏好保持不变。
- **PLAY**（LOOP / SONG）属于实时演奏控制，不随工程文件保存。

PROJECT 与 FILES 页的 FN 菜单：

| GRID 行 | 菜单项 |
|---|---|
| 第 1 行 | **NEW** PROJECT（新建）、**LOAD** PROJECT（进入 FILES）、**SAVE AS** PROJECT（另存并命名） |
| 第 4 行 | **SAVE**（<Key k="FN+S" />，有未保存改动时显示 `UNSAVED`）、**TAP**（<Key k="FN+T" />）、**REC**（<Key k="FN+PLAY" />）、**BACK**（返回原场景） |

## FILES 工程文件 {#setup-files}

按字母顺序列出 SD 卡上的全部工程文件，当前打开的工程前带有 `>` 标记。

<Shot name="setup-files">

- 使用 <Key k="ADD" /> / <Key k="SUB" /> 浏览（按住 <Key k="FN" /> 每次翻 8 行），按 <Key k="OK" /> 载入。
- 若当前工程有未保存改动，载入前会要求确认（<Key k="OK" /> 放弃改动并载入，<Key k="ESC" /> 取消）。
- 载入工程后默认停在 T1，并恢复该工程保存的键盘、和弦与琶音设置（旧版本不含这些字段的工程会保留当前设置）。

- 未插 SD 卡时列表为空（见[没插卡或卡坏了](./projects.mdx#storage-card)）。

## KEYS 键盘 {#setup-keys}

配置四条轨道共用的演奏区行为。除 **SELECT** 作为全局应用偏好保存外，其余各项均随工程保存。

<Shot name="setup-keys">
  <Mark at="cell:1,1">LAYOUT 排列（焦点）</Mark>
  <Mark at="cell:1,2">SCALE 音阶</Mark>
  <Mark at="cell:1,3">ROOT 根音</Mark>
  <Mark at="cell:1,4">OCTAVE 八度</Mark>
  <Mark at="cell:2,1">VELO 力度</Mark>
  <Mark at="cell:2,2">LOCK 锁定</Mark>
  <Mark at="cell:2,3">SELECT 选步方式</Mark>
  <Mark at="cells:3,1-4,4">键盘预览（音阶音带点，根音带下划线）</Mark>
  <KeyMark keys="G1">焦点：全亮</KeyMark>
  <KeyMark keys="G2-G7">可调设置：半亮</KeyMark>
  <Caption>SETUP KEYS 页面：七项键盘设置与两个八度的键盘预览。</Caption>
</Shot>

| 设置 | 选项 | 详见 |
|---|---|---|
| LAYOUT | PIANO / SCALE / CHROMA | [键盘排列](./play.mdx#play-keyboard) |
| SCALE / ROOT | 14 种音阶 / C–B | [音阶和根音](./play.mdx#play-scale) |
| OCTAVE | −3 至 +3 | [八度](./play.mdx#play-octave) |
| VELO | 1–127（默认 110），旋律轨固定力度 | [力度](./play.mdx#play-velocity) |
| LOCK | OFF / MUTE / SNAP | [音阶锁定 LOCK](./play.mdx#play-lock) |
| SELECT | SEQ 音符页（ROLL、STEP、鼓机）单击 GRID 的选步方式：**ONE** 每次单选一步；**MULTI** 每次单击增减多步选区 | [选中与编辑](./seq.mdx#seq-edit) |

**KEYS** 与 **SYSTEM** 两页的操作方式完全一致：

| 操作 | 按键 |
|---|---|
| 聚焦设置项 | 点按对应 GRID 键（焦点格反显） |
| 调节数值 | <Key k="ADD" /> / <Key k="SUB" />（支持长按连发；<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 步进 5） |
| 快速选值 | 按住对应 GRID 键，演奏区映射其完整范围（左上最小、右下最大） |
| 切换选项或开关 | 再次点按焦点键，或按 <Key k="OK" /> |
| 恢复默认 | 按 <Key k="FN+OK" />，或在 FN 菜单选择 **RESET** |

每页都会自动记住上次聚焦的设置项。

## SYSTEM 系统 {#setup-system}

<Shot name="setup-system">
  <Mark at="cell:1,1">VOLUME 主音量（焦点）</Mark>
  <Mark at="cell:1,2">KEY LED 按键灯亮度</Mark>
  <Mark at="cell:1,3">SCREEN 屏幕亮度</Mark>
  <Mark at="cell:1,4">LOG 运行日志</Mark>
  <Mark at="8,71,224,44">固件版本、SD 卡状态、可用内存与构建信息</Mark>
  <KeyMark keys="G1">焦点：全亮</KeyMark>
  <KeyMark keys="G2 G3 G4">可调设置：半亮</KeyMark>
  <Caption>SETUP SYSTEM 页面：四项硬件设置与设备运行状态信息。</Caption>
</Shot>

| 设置 | 范围 | 说明 |
|---|---|---|
| VOLUME | 0–100（默认 70，步进 2） | 采用符合人耳听感的对数音量曲线：0 为静音，1 约 −59 dB，50 约 −21 dB，70 约 −10 dB，100 为满量程（低音量段步幅大、高音量段更精细）。与[MIX：混音](./tape.mdx#tape-mix)的 MASTER 以及全局快捷键 <Key k="FN" /> + <Key k="7" /> / <Key k="U" />（[快捷调节](./fn.mdx#fn-quick)）联动。 |
| KEY LED | 0–15（默认 15） | 全部按键背光的全局亮度；聚焦该项时演奏区会显示亮度测试梯（[亮度设置与灯光测试](./lights.mdx#lights-ramp)）。 |
| SCREEN | 3–100%（默认 70%） | 屏幕背光亮度。 |
| LOG | ON / OFF（默认 ON） | 将运行与崩溃诊断日志写入 SD 卡（[日志](./projects.mdx#storage-log)）。 |

以上均为设备级设置，由所有鸣片应用共享并存放在 SD 卡 `CardenzaSynth/Settings/system.cfg` 中，切换工程不会覆盖它们。

页面下方在每次进入时逐行刷新设备状态：固件版本 **VERSION**、**SD CARD** 状态（`READY` 或 `NOT FOUND`，见[没插卡或卡坏了](./projects.mdx#storage-card)）、剩余内存 **MEMORY**（内部 RAM、历史最低水位及 PSRAM），以及 **BUILD**（提交号与编译时间）。
