# 效果器

每条轨道都配有独立的插入效果链和两路辅助发送；两路发送汇入共用的总线延迟与总线混响，最终与干声一起经过总线 EQ、总线压缩与磁带饱和输出。

```text
引擎 → DRIVE → CRUSH → FILTER → CHORUS → 轨道推子 ─┬─→ 输出
                                                  ├─ DELAY 发送 ─→ 总线延迟 ─┐
                                                  └─ REVERB 发送 → 总线混响 ─┴→ EQ → COMP → TAPE → 输出
```

效果参数分布在三个页面：

## 总线效果 {#fx-master}

总线效果位于 <Scene name="TAPE" /> <Page name="FX" /> 页，随工程保存（自工程格式 v4 起支持）：

<Shot name="tape-fx">
  <Mark at="cells:1,1-1,4">DELAY：速度同步磁带延迟</Mark>
  <Mark at="cells:2,1-2,4">REVERB：4 线 FDN 混响</Mark>
  <Mark at="cell:3,1">COMP：总线压缩器</Mark>
  <Mark at="cells:3,2-3,3">EQ：低频 / 高频搁架均衡（±12 dB）</Mark>
  <Mark at="cell:3,4">TAPE：磁带饱和</Mark>
  <Mark at="cells:4,1-4,4">当前速度下的回声预览与混响衰减曲线</Mark>
  <Caption>总线效果 FX 页面。</Caption>
</Shot>

- **DELAY**：**TIME** 按音符时值（1/32 至 1/2，默认 1/8D）与 BPM 同步。反馈回路内置 **TONE** 低通与 80 Hz 高通滤波器，切换时值时会产生磁带延迟式的平滑滑音。743 ms 以内的延迟分配 16 KB 缓冲，更长时值申请 32 KB 缓冲（最长 1.49 秒）；若内存不足则自动将时值折半直至可分配。
- **REVERB**：带宽约 4.5 kHz、音色温暖偏暗的 4 线反馈延迟网络（FDN）混响。
- 两路总线发送在处理前均降采样至 11.025 kHz，使延迟与混响呈现温润的 Lo-Fi 质感。

<Keywords k="总线, 主输出, 磁带延迟, 混响, 均衡, 压缩, master, bus, tape delay, reverb, eq, compressor, saturation" />

## 内存和 CPU {#fx-cpu}

效果器缓冲区采用按需分配、闲置释放机制：延迟线占用 16 KB（超过 743 ms 时为 32 KB），混响约占 8.8 KB，均位于板载 2 MB PSRAM 中；每轨合唱另占 1 KB。

- 若 PSRAM 不足导致延迟或混响分配失败，对应总线保持静音并在 FX 页与信号链上显示 `NO MEM`。所有效果关闭时，音频输出与无效果直通逐位一致。
- 各引擎单轨复音数上限：DX7 为 4 复音，JUNO 与 DRUMS 为 6 复音，SAMPLER 为 4 复音。超出上限时自动抢占最早触发的声部（优先回收已释音的尾音）。
- 音频引擎每 256 帧的实时计算预算为 5.8 ms，由 ESP32-S3 双核协同渲染。算力吃紧时，系统会从当前复音数最多的轨道中平滑淡出最不显眼的声部（先回收释音尾音，再淡出最轻的保持音）。复音裁剪仅限同轨内部，不会影响其他轨道，也不会拖慢节拍。

:::warning

密集和弦同时叠加大量效果器时仍可能引发爆音，此时可适当减少同时发声数或关闭一两个效果器。

:::
