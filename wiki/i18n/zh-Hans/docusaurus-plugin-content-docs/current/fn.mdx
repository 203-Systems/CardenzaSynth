# FN 菜单与快捷键

<Key k="FN" /> 用于调用当前页面的**快捷菜单**与组合功能：按住 <Key k="FN" /> 会在 GRID 上展开当前页可用操作并启用全键盘第二功能；单击 <Key k="FN" /> 则可将菜单常驻打开。

<Keywords k="fn, 功能键, 第二功能, 菜单, function, menu, shift" />

| 操作 | <Key k="hold FN" /> 按住 FN | <Icon name="tap" /> 单击 FN（常驻菜单） |
|---|---|---|
| 执行菜单项 | 按 <Key k="FN" /> + 对应 GRID 键，或 <Key k="FN" /> + 对应字母键 | 直接点按对应 GRID 键（执行后自动关闭菜单） |
| 关闭菜单 | 松开 FN | 再按一次 <Key k="FN" /> 或 <Key k="ESC" /> |
| 演奏区 PADS | 静音，仅响应字母快捷键与快捷调节 | 正常弹奏音符 |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> | 大步调节（SEQ 音符页未选步时切换上/下一个 Pattern）与第二 OK 功能（见[第二功能（字母键与四周的键）](#fn-shortcuts)） | ADD / SUB 无效；<Key k="FN+OK" /> 仍可触发第二 OK 功能 |

- 按住超过 250 毫秒视为长按，更快松开则视为单击并常驻打开菜单。
- **操作反馈**：按住 FN 执行菜单项时，对应格子会短暂高亮为黄色，底部状态栏同步提示执行结果（如 `COPIED P01`、`VIEW STEP`）。灰显项目表示当前页面不可用，点按会提示 `... NOT HERE`。
- 第 1–3 行随当前页面动态变化，第 4 行在全界面保持一致：**SAVE**（保存工程）、**TAP**（敲击定速）、**REC**（录音待命）与 **SETUP**（身处 SETUP 内时变为 **BACK**）。
- 全局设置统一归入[0 SETUP 设置](./setup.mdx)，<Key k="FN" /> + <Key k="1" />–<Key k="5" /> 未分配功能。

每个菜单格包含三部分信息：

- **名称与快捷键**：顶部为功能名，右上角黄色标注对应的 FN 快捷键（如 `C` 代表 <Key k="FN+C" />，`OK` 代表 <Key k="FN+OK" />，`PLAY` 代表 <Key k="FN+PLAY" />）。
- **对象或状态**：第二行注明作用对象（如 `PATTERN`、`STEPS`、`ROW 2` 或音源名）或当前状态（如 `ROLL`、`120 BPM`、`OFF`）。
- **灯光状态**：<Led state="half">半亮</Led> 表示可用，<Led state="full">全亮</Led> 表示已开启的开关（屏幕反显，如 `VIEW STEP`、`REC ARMED`、`PLAY SONG`），<Led state="off">灭</Led> 且带虚线框表示当前不可用（如剪贴板为空时的 `PASTE` 或未选步时的 `SCOPE`）。

## 每个画面的菜单 {#fn-menus}

| 页面 | 第 1–3 行菜单项 |
|---|---|
| INSTR（所有页） | **PRESETS**（浏览音色）、**SAVE** / **SAVE AS**（保存 / 另存音色）、**ENGINE**（选择音源）、**RESET** `OK`（将焦点参数恢复默认，适用于参数页及 CHORD / ARP）；SAMPLER 轨额外包含 **SAMPLES**（采样列表）、**RECORD**（录采样）与 **PREVIEW**（试听）。 |
| SEQ（所有页） | **COPY** `C`、**PASTE** `V`、**CLEAR** `X`、**QUANT** `Q`（作用于选中步进，未选步时作用于整个 Pattern）、**DUP** `D`（复制 Pattern 至下一空槽，最多 16 个）、**VIEW**（切换 ROLL / STEP，鼓轨不可用）、**RECORD**（打开 RECORD 面板与无感录制 take）、**SCOPE** `OK`（选步时切换编辑全部和弦音或单音）、**PAGE −** / **PAGE +**（长 Pattern 切换 16 步页）、**LEN −** / **LEN +**（调整 Pattern 长度：1、2、4、8、16，此后按 16 步递增至 256）。 |
| TAPE SESSION | **LAUNCH**（发射光标所在整行）、**ADD** TO SONG `OK`（将当前播放/排队的 Pattern 组合追加为 SONG 新段落）。 |
| TAPE SONG | **COPY** `C`、**PASTE** `V`（插入到光标之后）、**DELETE** `X`、**DUP** `D`（作用于光标所在段落 `ROW n`）、**PLAY** `OK`（切换 SONG / LOOP 模式）。 |
| TAPE MIX | **UNMUTE** ALL（全部取消静音）、**UNSOLO** ALL（全部取消独奏）。 |
| TAPE SENDS / FX | **RESET** `OK`（恢复焦点参数默认值）。 |
| SETUP PROJECT / FILES | **NEW**、**LOAD**、**SAVE AS**（工程管理）。 |
| SETUP KEYS / SYSTEM | **RESET** `OK`（恢复焦点设置默认值）。 |
| **第 4 行（全部页面）** | **SAVE** `S`（保存工程，有未保存改动时显示 `UNSAVED`）、**TAP** `T`（敲击定速并显示 BPM）、**REC** `PLAY`（录音待命，开启时全亮）、**SETUP**（进入 0 SETUP；身处 SETUP 时显示 **BACK** 返回原场景）。 |

| 快捷键 | 功能 |
|---|---|
| <Key k="FN" /> + GRID | 执行对应菜单项 |
| <Key k="FN" /> + <Key k="ESC" /> | 全部停止：停止音序器、切断所有发声与全部 ARP（`ALL STOP`） |
| <Key k="FN" /> + <Key k="TAB" /> | 上一条轨道 |
| <Key k="FN" /> + <Key k="CTRL" /> | 上一页（单按 <Key k="CTRL" /> 为下一页） |
| <Key k="FN" /> + <Key k="ADD" /> / <Key k="SUB" /> | 大步调节：宽范围参数 ×10（含 BPM ±10）、窄范围 ×3、SETUP 设置 ×5、VOICE 页跳 10 个音色、列表翻 8 行；在 SEQ 音符页与 PATTERN 页（未选步时）切换上/下一个 Pattern（播放中排队；若已选步则大步调整选中步参数）。 |
| <Key k="FN" /> + <Key k="OK" /> | 当前页面的第二 OK 功能：INSTR / SENDS / 总线 FX / SETUP 设置页恢复焦点参数默认；SEQ 音符页切换和弦编辑范围（全部 / 单音）；SESSION 追加到 SONG；SONG 切换 SONG / LOOP；RECORD 面板将 take 合并至当前 Pattern；采样列表重命名或删除文件。 |
| <Key k="FN" /> + <Key k="PLAY" /> | 开关实时录音待命（REC） |
| <Key k="FN" /> + <Key k="C" /> / <Key k="V" /> | 复制 / 粘贴（选中的步、当前 Pattern 或 SONG 段落） |
| <Key k="FN" /> + <Key k="X" /> | 清除选中步或整个 Pattern（整段清除需确认），或在 SONG 中删除当前段落 |
| <Key k="FN" /> + <Key k="Q" /> | 将选中步或整个 Pattern 量化对齐至整步 |
| <Key k="FN" /> + <Key k="D" /> | 将当前 Pattern 复制到下一空槽，或在 SONG 中复制当前段落 |
| <Key k="FN" /> + <Key k="T" /> | 敲击定速（Tap tempo）：连续按两次以上按间隔设定 BPM |
| <Key k="FN" /> + <Key k="S" /> | 保存工程（未命名工程自动保存为 SONG 01、SONG 02……） |
| <Key k="FN" /> + <Key k="F" /> | 在音色与采样列表中打开名称搜索（见[输入画面里的 FN：黄色丝印](#fn-yellow)） |
| <Key k="FN" /> + <Key k="1" />–<Key k="5" /> | 未分配功能 |

:::note

字母快捷键仅在当前页面菜单包含该项时有效（此时对应按键半亮提示）；<Key k="S" /> 与 <Key k="T" /> 全局有效。若通过单击 FN 常驻打开菜单（未按住 FN），演奏区仍用于弹奏音符，不触发字母快捷键。

:::

## 输入画面里的 FN：黄色丝印 {#fn-yellow}

在弹窗与输入界面（文字输入、音色/采样列表、音源选择、RECORD 面板、确认框）中，按住 <Key k="FN" /> 不再展开菜单，而是启用键帽上印制的**黄色丝印**功能：

<Keymap>
  <Group keys="FN">按住</Group>
  <Group keys=";">上</Group>
  <Group keys=".">下</Group>
  <Group keys=",">左</Group>
  <Group keys="/">右</Group>
  <Group keys="ADD SUB">翻页</Group>
  <Group keys="F">搜索（列表）</Group>
  <Caption>在输入界面按住 FN，GRID 右下角四个键切换为方向键。</Caption>
</Keymap>

- 在音色与采样列表中，演奏区不参与打字，按 <Key k="FN+F" /> 打开搜索框（最多 16 个字符），按 <Key k="OK" /> 筛选结果。按一次 <Key k="ESC" /> 清空筛选条件，再按一次关闭列表。
- 除文字输入界面外（ESC 仅作取消），<Key k="FN+ESC" /> 在各弹窗中同样可执行全部停止。

## 输入文字 {#fn-text}

为工程、音色或采样命名时，整个键盘切换为标准字符输入模式，按各键帽标识输入：

  <Caption>SAVE PROJECT AS 文本输入界面。</Caption>

- 支持字母、数字、空格（按 <Key k="PLAY" />，不可位于首位）和 `-`，最多 24 个字符（搜索框上限为 16 字符）。SAVE AS 默认预填当前工程名（未命名时为 `SONG`）。
- 右上角键（`del`）用于退格删除，<Key k="OK" /> 确认保存，<Key k="ESC" /> 取消。
- 按住 <Key k="FN" /> 配合 <Key k="," /> / <Key k="/" /> 左右移动光标，配合 <Key k=";" /> / <Key k="." /> 跳至行首或行尾，配合 `del` 向后删除。
- 光标在字符间显示为竖线，位于末尾时显示为实心方块。
