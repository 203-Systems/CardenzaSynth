# 3 TAPE 走带

**TAPE** 将四条轨道汇总在一起，用于片段发射、歌曲编排、混音、效果发送与总线效果。按 <Key k="CTRL" /> 在五个子页面间切换：

<Page name="SESSION" /> <Page name="SONG" /> <Page name="MIX" /> <Page name="SENDS" /> <Page name="FX" />

工程保存、载入与全局 BPM 位于 <Scene name="SETUP" />（见[PROJECT 工程](./setup.mdx#setup-project)与[FILES 工程文件](./setup.mdx#setup-files)）。除主输出音量外，TAPE 这五页上的全部参数均随工程保存。每一页 FN 菜单的第 4 行均保持统一：SAVE（<Key k="FN+S" />）、TAP（<Key k="FN+T" />）、REC（<Key k="FN+PLAY" />）与 SETUP。

<Keywords k="走带, 整首歌, 编排, 混音, 四轨, tape, song, arrangement, mixer" />

## SESSION：像 Ableton 那样发射 {#tape-session}

每列对应一条轨道（按轨道配色），每行对应一个 Pattern 槽位，每个格子内以缩略图预览该 Pattern 的 16 步内容。

<Strip>
  <Step keys="PLAY, G6" shot="tape-session-queued" at="cell:2,2">播放中点按任意格子可将其排队，待该轨本圈循环结束后切换。格子显示 `NXT`，按键灯 <Led state="blink">闪烁</Led>。</Step>
  <Step >本圈播完后，T2 自动切换至 P02。停止状态下点按格子会立即切换。</Step>

- 点按任意格子即可在该轨发射对应 Pattern（同时将该轨设为当前轨）。点按某轨最后一个 Pattern 下方的 `+` 格，可新建空 Pattern 并立即发射。
- 用 <Key k="ADD" /> / <Key k="SUB" /> 上下移动光标行并滚动列表，按 <Key k="OK" /> 同步发射光标所在的整行 Pattern。
- 按 <Key k="FN+OK" /> 可把四轨当前正在播放（或已排队）的 Pattern 组合捕获为 **SONG** 末尾的新段落，其小节长度自动匹配其中最长的 Pattern。
- FN 菜单包含 **LAUNCH**（发射光标所在整行）与 **ADD** TO SONG（等同 <Key k="FN+OK" />）。
- 在 SESSION 中发射片段会自动退出 SONG 模式并回到 LOOP 模式。正在播放的格子以绿底、▶ 及走动的播放头标示。

## SONG：编排整首歌 {#tape-song}

SONG 按从左到右的时间轴排布全曲结构：每**列**为一个段落，每**行**为一条轨道，每个格子记录该轨在此段落播放的 Pattern 编号，并标注该段落的小节数（`xN`）。

<Shot name="tape-song">
  <Mark at="cells:1,1-4,1">第 1 段</Mark>
  <Mark at="cells:1,2-4,2">第 2 段</Mark>
  <Mark at="cell:1,1">已选中格子</Mark>
  <Mark at="47,15,17,10">段落小节数（xN）</Mark>
  <Mark at="cells:1,3-4,3">+ 列：追加新段落</Mark>
  <Mark at="199,111,31,12">LOOP / SONG 播放模式</Mark>
  <Caption>SONG 视图：每列为一个段落，每行为一条轨道。</Caption>
</Shot>

- 点按格子将其选中；再次点按同一格可在编辑 **Pattern** 与编辑**小节数**之间切换（编辑小节数时 `xN` 变为黄色）。`--` 表示该轨在此段落静音。
- 点按末段右侧的 `+` 列会追加一段（默认复制末段内容；空歌曲时填入四轨当前 Pattern）。
- 用 <Key k="ADD" /> / <Key k="SUB" /> 更改当前格子的 Pattern（含 `--`）或段落小节数（1–16）；<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 始终直接调整小节数。
- 按 <Key k="OK" /> 从当前选中段落开始播放（自动切入 SONG 模式；若已在播放则立即跳转）；按 <Key k="FN+OK" /> 切换 SONG / LOOP 模式。
- 按 <Key k="FN+C" />、<Key k="FN+V" />、<Key k="FN+X" />、<Key k="FN+D" /> 可复制、粘贴（插入光标后）、删除或复制当前段落。FN 菜单同样提供这四项（标注 `ROW n`）以及 **PLAY**（SONG / LOOP 切换）。
- [PROJECT 工程](./setup.mdx#setup-project)页的 **PLAY** 开关同步控制此 SONG / LOOP 状态。该开关属于现场演奏控制，不写入工程文件；在 SESSION 中发射片段会自动切回 LOOP。

在 **SONG** 模式下，每段依次播放 `xN` 小节（1 小节 = 16 步）并循环全曲；在 **LOOP** 模式下，各轨独立循环当前 Pattern。正在播放的段落带绿色播放头，等待切入的段落带黄色框提示。

:::tip

可以在 SESSION 中即兴组合段落，满意后按 <Key k="FN+OK" /> 直接追加到 SONG 末尾。

:::

  <KeyMark keys="G13-G16">已启用的 SEQ：全亮</KeyMark>
  <Caption>MIX 混音页：四轨推子、MUTE / SOLO / SEQ 开关与底部主音量。</Caption>

- GRID 每列对应一条轨道：第 1 行选轨，第 2 行 **MUTE**（静音），第 3 行 **SOLO**（独奏），第 4 行 **SEQ**（音序开关）。
- 用 <Key k="ADD" /> / <Key k="SUB" /> 调节当前选中轨的音量（0–100，默认 100；按住 <Key k="FN" /> 步进 ±10）；按 <Key k="OK" /> 在选中轨与 **MASTER** 主音量之间切换焦点。按住某轨第 1 行按键可直接通过 32 颗演奏键快速定位音量值。
- **MASTER** 即设备输出主音量，与[SYSTEM 系统](./setup.mdx#setup-system)中的 **VOLUME** 同步，归属设备全局设置而非工程；各轨音量、静音、独奏和 SEQ 状态随工程保存。
- 当任意轨道处于静音或独奏状态时，FN 菜单会启用 **UNMUTE ALL** 与 **UNSOLO ALL**。

:::tip

在任意页面按住 <Key k="TAB" /> 打开的轨道地图均采用与 MIX 相同的四列布局。

:::

<Keywords k="混音, 推子, 音量, 静音, 独奏, 主音量, mix, mixer, fader, level, mute, solo, master volume" />

- 点按格子选中对应参数（同步切换至该轨），用 <Key k="ADD" /> / <Key k="SUB" /> 调节（按住 <Key k="FN" /> 步进 10），或按住格子直接通过演奏区选值。未启用的格子呈暗显。
- 按 <Key k="OK" />（或再次点按 CHORUS 格）可切换 CHORUS 模式，或将其他参数在关闭与原值之间一键切换；按 <Key k="FN+OK" /> 或 FN 菜单 **RESET** 恢复默认。
