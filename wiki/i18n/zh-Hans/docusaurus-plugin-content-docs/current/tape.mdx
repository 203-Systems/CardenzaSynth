# 3 TAPE 走带

TAPE 是四轨合在一起：哪一段放哪些 Pattern、整首歌的编排、混音、发送和总线效果。五页（<Key k="CTRL" /> 翻）：

<Page name="SESSION" /> <Page name="SONG" /> <Page name="MIX" /> <Page name="SENDS" /> <Page name="FX" />

保存、载入和工程的 BPM 属于全局，在 <Scene name="SETUP" /> 里：见 [PROJECT 工程](./setup.mdx#setup-project) 和 [FILES 工程文件](./setup.mdx#setup-files)。这五页上除了主音量，全部属于工程。每一页 FN 菜单的最下面一行都一样：SAVE（<Key k="FN+S" />）、TAP（<Key k="FN+T" />）、REC（<Key k="FN+PLAY" />）和 SETUP。

每列一条轨道（轨道色），每行一个 Pattern 槽；每格画出这个 Pattern 的 16 步。

<Strip>
  <Step keys="PLAY, G6" shot="tape-session-queued" at="cell:2,2">播放中点一格：这一轨在这一圈结束时切换。格子写着 NXT，键灯 <Led state="blink">闪烁</Led>。</Step>
  <Step >一圈播完，T2 换成 P02。停止时点格子立即切换。</Step>
</Strip>

- 点格子：让这一轨播这个 Pattern（同时这一轨成为当前轨）。一轨最后一个 Pattern 之后的「+」新建一个空的并开始播。
- <Key k="ADD" /> / <Key k="SUB" />：光标行上移 / 下移并滚动；<Key k="OK" />：发射光标所在的整行（所有有这个 Pattern 的轨道）。
- <Key k="FN+OK" />：把每轨正在播（或排队）的 Pattern 记成 SONG 末尾的新一段；这一段的长度等于其中最长的 Pattern。
- FN 菜单：**LAUNCH**（发射光标所在的行）和 **ADD** TO SONG（同 <Key k="FN+OK" />）。
- 从 SESSION 发射会退出 SONG 模式。正在播的格子是绿色底、▶ 和走动的播放头。

## SONG：编排整首歌 {#tape-song}

整首歌像一段磁带：每**列**是一段（从左往右是时间），每**行**是一条轨道，格子里是这一段要播的 Pattern 和小节数（xN）。

<Shot name="tape-song">
  <Mark at="cells:1,1-4,1">第 1 段</Mark>
  <Mark at="cells:1,2-4,2">第 2 段</Mark>
  <Mark at="cell:1,1">选中的格子</Mark>
  <Mark at="47,15,17,10">小节数 xN</Mark>
  <Mark at="cells:1,3-4,3">+ 列：追加一段</Mark>
  <Mark at="199,111,31,12">LOOP / SONG 模式</Mark>
  <Caption>SONG：每列是一段，每行是一轨。</Caption>
</Shot>

- 点格子选中，再点一次同一格在「Pattern」和「小节数」之间切换（编辑小节数时这一段的 xN 变黄）。`--` 表示这一轨在这一段不出声。
- 点最后一段之后的 + 列：追加一段，内容复制最后一段（歌曲还是空的时候：每轨正在播的 Pattern）。
- <Key k="ADD" /> / <Key k="SUB" />：换这一格的 Pattern（包括 `--`），或改这一段的小节数（1–16）；<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 总是改小节数。
- <Key k="OK" />：从这一段开始播（自动进入 SONG 模式；正在播时直接跳过去）；<Key k="FN+OK" />：切换 SONG / LOOP。
- <Key k="FN+C" /> / <Key k="FN+V" /> / <Key k="FN+X" /> / <Key k="FN+D" />：复制、粘贴（插在光标之后）、删除、复制一段。FN 菜单里也有（COPY、PASTE、DELETE、DUP，写着 ROW n），另有 PLAY 切换 SONG / LOOP。
- [PROJECT 工程](./setup.mdx#setup-project) 上的 PLAY 开关就是同一个 SONG / LOOP 设置。它是演奏控制，不存进工程；在 SESSION 里发射会切回 LOOP。

SONG 模式下每段播放 xN 小节（1 小节 = 16 步）后进入下一段，结尾回到第一段。LOOP 模式即各轨循环自己的当前 Pattern。正在播的一段有绿色的磁头扫过；等着开始的一段有黄色虚线框。

:::tip

在 SESSION 里搭好一个组合，<Key k="FN+OK" /> 就把它记成 SONG 的下一段：边玩边编排。

:::

## MIX：混音 {#tape-mix}

<Shot name="tape-mix">
  <Mark at="cells:1,1-4,1">T1 一列</Mark>
  <Mark at="cell:1,2">选中轨</Mark>
  <Mark at="cells:2,1-2,4">MUTE 静音</Mark>

  <Mark at="cells:4,1-4,4">SEQ 音序开关</Mark>

  <KeyMark keys="G2">选中：全亮</KeyMark>
  <KeyMark keys="G5-G12">MUTE / SOLO 没开：半亮</KeyMark>
  <KeyMark keys="G13-G16">SEQ 开着：全亮</KeyMark>
  <Caption>MIX：四个推子，MUTE / SOLO / SEQ 开关，底部是主音量。</Caption>
</Shot>

- GRID 每列一条轨道：行 1 选中、行 2 静音、行 3 独奏、行 4 音序开关。
- <Key k="ADD" /> / <Key k="SUB" /> 调选中轨的音量（0–100，默认 100；<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 一次 10）；<Key k="OK" /> 在选中轨和 MASTER 之间切换。按住某一轨第 1 行的键：演奏键就是它的音量值。
- MASTER 是设备的输出音量，和 [SYSTEM 系统](./setup.mdx#setup-system) 的 VOLUME 是同一个：属于设备，不属于工程。各轨音量、静音、独奏和 SEQ 开关存在工程里。
- FN 菜单：**UNMUTE** ALL 全部取消静音、**UNSOLO** ALL 全部取消独奏（有轨道被静音 / 独奏时才能用）。

:::tip

按住 <Key k="TAB" /> 在任何画面都能用同一个布局（轨道地图）。

:::

- 点格子选中（同时选中那一轨），<Key k="ADD" /> / <Key k="SUB" /> 调整（<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 一次 10）；按住格子，演奏键就是它的取值。关着的格子变暗。
- <Key k="OK" />，或在 CHORUS 格子上再点一次：CHORUS 换模式，其它格子关闭 / 恢复原值；<Key k="FN+OK" /> 或 FN 菜单的 RESET：恢复默认。
- 这些就是这一轨 INSTR FX 页上的那几个 `fx.*` 值（[发送：延迟和混响](./effects.mdx#fx-sends)）。
