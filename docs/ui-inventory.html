Sequencer · 14 个页面与状态
默认 Home 显示演奏键盘；同时按下 + / − 切换常驻 4×4 Sequencer 网格，并结束临时步进编辑，不停止序列播放或改变键盘配置。单独按住 + 或 − 才显示 Pattern，松开 OCT 和相关操作键即退出。普通 Home 上按实体 HOME 也可切换。SYS → SEQ 左下角 GRID / KEYS 也可切换并回 Home。网格在 NOTE / LEN / VEL / STEP 编辑中保留；编辑、Pattern 层或菜单中按 HOME 只取消/返回，保留所选视图。实体第 1–8 列仍演奏，第 9–12 列仍为步进键。
每张画板对应一个页面或有独立操作的状态。点击查看操作、验收状态和代码入口。参数编辑器复用同一模板，DX7 六个 Operator 分别列出。

与 NullPerator 对齐什么

复用语义与组件规则

参考文件与 NullPerator UI2 的黑绿底色、青色编辑光标、绿色播放指示、分组参数和上下文帮助已有对应关系。统一的是可读性和行为，不是方屏坐标。

编辑 / 选中播放警告错误
  • 让编辑光标与播放步进同时可辨认。
  • 参数名、当前值、单位 / 含义保持稳定层级。
  • 空、加载、写入、成功、失败都有真实反馈。
  • 命名、浏览、确认共用行为和操作位置。

保留 Cardenza 的输入与比例

NullPerator UI2 是 240×240；Cardenza 是 240×135，只有相同宽度下 56.25% 的高度。现有 4 行两侧按键、32 个演奏键和 16 个步进键决定了布局。

  • 1×4 与 2×4 是实体键映射，不改成底部触屏工具栏。
  • 小菜单优先 1×4，密集音源组才用 2×4。
  • FILE 直接浏览，REC 始终在 Sampler 根页面。
  • 1×4 的前进确认在最底部，返回在其上一格。
