# 版本 {#changelog}

说明书的版本号在右上角（例如 v1.2.0），后面是它所描述的固件版本（代码提交号，带 `+` 表示包含未提交的改动）和生成日期。说明书里的参数表、截图和按键灯都是从固件代码直接生成的，所以总是和那个固件版本一致。

## 1.5.0 · 2026-11-04 {#version-1-5-0}

- **PIANO 排列改成两个完整的八度**：每两行一个八度，白键在下、黑键在上；下面两行从左下角的 C3 开始，上面两行高一个八度。屏幕上的键盘也画这两个八度（C3 到 C5）。见 [[#play-keyboard]]。
- 待机（屏保）去掉了：机器一直显示当前的画面和键灯。

## 1.4.0 · 2026-11-03 {#version-1-4-0}

- **入门教程**：说明书网站现在先打开教程：三课图解编曲（八音盒、四个八音盒、排成一首歌），八课学机器（按键分区、出声、换界面、换轨道、第一个 Pattern、音阶、和弦和琶音、第一首歌）。每一课几步，看图跟着按；接着机器时做对了网页会说「学会了」。
- 用 USB 接上 Cardenza，浏览器问的时候点「允许」：机器进入教程模式，跟着课程换到对应的画面，要按的键会闪，做对了网页说「学会了」；你自己的工程先被存好，教程结束就回来。需要新固件。
- 这本说明书成了「字典」：查某个键、某一页、某个设置。教程和字典在顶上切换，教程页的搜索也查字典。

## 1.3.0 · 2026-11-03 {#version-1-3-0}

整本说明书对照当前固件逐章重新核对，截图全部重拍：

- **场景编号和屏幕一致**：0 SETUP、1 INSTR、2 SEQ、3 TAPE。按住 ESC 时 GRID 第 1 列是 SETUP，第 2–4 列是 INSTR、SEQ、TAPE。
- SETUP 只剩 PROJECT、FILES、KEYS、SYSTEM 四页。**和弦和 ARP 属于每条轨道**，在 INSTR 的 CHORD、ARP 页（鼓轨没有）；几条轨道的 ARP 可以同时跑，开关叫 HOLD。
- 开机和每个工程从 {{track:1}} 鼓机开始，在 INSTR VOICE 页。
- Pattern 1–256 步，GRID 一次显示 16 步，SEQ 菜单里有 PAGE 和 LEN。
- 音色和采样列表里按键不再直接打字：{{key:FN+F}} 打开搜索。
- 工作状态自动存在机器内部（不需要卡），随时拔电也不丢；见 [[#project-session]]。
- USB：接电脑后是 USB MIDI 和 USB 音频设备；见 [[#faq-midi]]。
- HOME 侧键在 Groovebox 里不用，全部停止是 {{key:FN+ESC}}。
- SYSTEM 页 VOLUME 恢复默认是 50（之前误为 85）。

## 1.2.0 · 2026-10-27 {#version-1-2-0}

四个场景，FN 变成当前画面的菜单：

- **四个场景，分两类**：1 INSTR（当前轨的声音）、2 SEQ（当前轨弹什么）、3 TAPE（四轨合在一起：SESSION、SONG、MIX、SENDS、FX），以及新的 **4 SETUP**（全局与设置：PROJECT、FILES、KEYS、CHORD、ARP、SYSTEM）。见 [[#nav-scenes]] 和 [[#setup]]。
- 单击 ESC 只在 1 → 2 → 3 之间循环。进 SETUP 要按住 ESC 再按 GRID 第 4 列（场景地图现在有四列），或用 FN 菜单的 SETUP；在 SETUP 里单击 ESC 回到进来之前的场景。
- PROJECT 和 FILES 从 TAPE 搬到 SETUP。工程页还多了 PLAY（LOOP / SONG）。FN+S 不再问名字：还没起名的工程存成 SONG 01、SONG 02……
- **FN 是当前画面的菜单**（[[#fn-menu]]）：按住时 GRID 显示这一页能做的事（复制、粘贴、音色、发射、恢复默认……），每个画面最下面一行都是 SAVE、TAP、REC、SETUP；单击 FN 菜单常驻。FN 面板、QUICK 页、FN SETUP 和 FN + 1…5 都去掉了；设置在 SETUP 的 KEYS、CHORD、ARP、SYSTEM 页。FN + CTRL 改成上一页，FN + ADD / SUB 是大步调整。
- 开机进入 1 INSTR 的 VOICE 页（当前轨仍是 T2）。
- 播放时的 STEP 视图：播放头走进的那一步绿色闪一下并保持绿框，后面不留拖尾。

## 1.1.4 · 2026-10-26 {#version-1-1-4}

- 按键灯做伽马校正：硬件层只给总亮度做了校正，每个键的亮度是线性的，所以固件先按人眼把亮度换算好再点灯。「半亮」现在是键能发出的最暗的光，和全亮一眼就能分开。

## 1.1.0 · 2026-10-26 {#version-1-1}

说明书改成和产品一样的样子：

- 整页是设备的深色界面：模拟器的面板、屏幕边框和按键，屏幕上的颜色（ESC 橙、TAB 青、FN 黄、CTRL 紫、PLAY 绿、轨道色）。
- 截图上要看的地方用**高亮**标出：其余部分变暗，高亮处是屏幕上的黄色虚线框，并编上号；图下面按编号写着每一处是什么。按键灯图上的键也一样。

- 场景、轨道、页签、按键灯状态在文字里也画成屏幕上的样子。

## 1.0.0 · 2026-10-26 {#version-1-0}

第一版说明书，对应的固件功能：

- 三个场景 INSTR / SEQ / TAPE，四条轨道（DRUMS、JUNO、DX7、SAMPLER），按住左侧键的地图导航；ESC 单击循环场景。
- FN 面板：KEYS、CHORD、ARP、PROJECT、SYSTEM 五页；按住 FN 快捷调节 BPM、音量、八度；输入画面里的黄色丝印方向键和文字光标。
- SEQ：ROLL 钢琴卷帘（默认）和 STEP 步进录制两种视图；OK 是录音键（单击切换视图、按住打开 RECORD 面板）；无感录制（Capture）最近 8 段弹奏，可以一小节一小节放进新 Pattern 或合并。
- 演奏：钢琴 / 音阶 / 半音排列，14 种音阶，音阶锁定，一键和弦和转位，ARP。
- TAPE：SESSION（Ableton 式发射）、SONG 编排、MIX、SENDS、总线效果、工程与文件。
- 按键灯：灭 / 半亮 / 全亮 / 闪烁，半亮用暗脉冲；屏幕两侧色块与按键灯同步；KEY LED 亮度梯测试。
- 存储协议：SD 卡目录、设置文件、session 保留；网页模拟器（同一套固件代码）。
- 说明书：每张截图都能换成运行中的设备跟着操作（一页只运行一台，最后点开的那一节）；用 USB 连接真机，用真机按键操作说明书里的设备。
