# 版本 {#changelog}

说明书的版本号在右上角（例如 v1.1.4），后面是它所描述的固件版本（代码提交号，带 `+` 表示包含未提交的改动）和生成日期。说明书里的参数表、截图和按键灯都是从固件代码直接生成的，所以总是和那个固件版本一致。

## 1.1.4 · 2026-10-26 {#version-1-1-4}

- 按键灯做伽马校正：硬件层只给总亮度做了校正，每个键的亮度是线性的，所以固件先按人眼把亮度换算好再点灯。「半亮」现在是键能发出的最暗的光，和全亮一眼就能分开。

<!-- keywords: 1.1.4, 伽马, 校正, 半亮, 太亮 -->

## 1.1.3 · 2026-10-26 {#version-1-1-3}

- 开机和新工程从 {{track:2}} 开始：演奏区一开机就是钢琴排列，白键、黑键半亮，缺口（Shift、D、J）不亮，按下的键全亮。

<!-- keywords: 1.1.3, 开机, 默认轨道, 钢琴排列 -->

## 1.1.2 · 2026-10-26 {#version-1-1-2}

- 硬件层 CardenzaHAL 更新：每个键有 16 档真实亮度，KEY LED 总亮度是独立的硬件调光。「半亮」改成 20 % 的点亮时间，看上去约一半亮，和全亮分得很开；KEY LED 亮度梯显示 0–15 里的 8 档。

<!-- keywords: 1.1.2, 亮度, 按键灯, 16 档 -->

## 1.1.1 · 2026-10-26 {#version-1-1-1}

- 按键灯按设备的硬件层 CardenzaHAL 原样工作：四档真实亮度 25 / 50 / 75 / 100 %，「半亮」是 25 %。说明书里的按键灯图、KEY LED 亮度梯和网页模拟器都按这个模型画。
- 音量只由音频芯片调节一次（以前还会在软件里再调一次，音量调低时比设定更小）。

<!-- keywords: 1.1.1, 亮度, 按键灯, 音量 -->

## 1.1.0 · 2026-10-26 {#version-1-1}

说明书改成和产品一样的样子：

- 整页是设备的深色界面：模拟器的面板、屏幕边框和按键，屏幕上的颜色（ESC 橙、TAB 青、FN 黄、CTRL 紫、PLAY 绿、轨道色）。
- 截图上要看的地方用**高亮**标出：其余部分变暗，高亮处是屏幕上的黄色虚线框，并编上号；图下面按编号写着每一处是什么。按键灯图上的键也一样。
- 按键都画成真机的键帽（和模拟器一样的字和颜色），按住的键标着「按住」，GRID 键同时写着键帽和格子编号（如 9 G1）。
- 操作都画成一步一步的编号小图：按哪个键 → 屏幕变成什么 → 发生了什么。新增 21 张截图（打鼓、切轨提示、和弦、ARP、无感录制放进 Pattern、排队发射、保存……）。
- 场景、轨道、页签、按键灯状态在文字里也画成屏幕上的样子。

## 1.0.0 · 2026-10-26 {#version-1-0}

第一版说明书，对应的固件功能：

- 三个场景 INSTR / SEQ / TAPE，四条轨道（DRUMS、JUNO、DX7、SAMPLER），按住左侧键的地图导航；ESC 单击循环场景。
- FN 面板：KEYS、CHORD、ARP、PROJECT、SYSTEM 五页；按住 FN 快捷调节 BPM、音量、八度；输入画面里的黄色丝印方向键和文字光标。
- SEQ：ROLL 钢琴卷帘（默认）和 STEP 步进录制两种视图；OK 是录音键（单击切换视图、按住打开 RECORD 面板）；无感录制（Capture）最近 8 段弹奏，可以一小节一小节放进新 Pattern 或合并。
- 演奏：钢琴 / 音阶 / 半音排列，14 种音阶，音阶锁定，一键和弦和转位，ARP。
- TAPE：SESSION（Ableton 式发射）、SONG 编排、MIX、SENDS、总线效果、工程与文件。
- 按键灯：灭 / 半亮 / 全亮 / 闪烁，半亮用暗脉冲；屏幕两侧色块与按键灯同步；KEY LED 亮度梯测试。
- 存储协议：SD 卡目录、设置文件、session 保留；网页模拟器（同一套固件代码）。
- 说明书：每张截图都能换成运行中的设备跟着操作（一页只运行一台，最后点开的那一节）；用 USB 连接真机，用真机按键操作说明书里的设备。
